# 智能教学协同系统服务端 需求清单 功能需求文档

> 说明：本文档用于明确“智能教学协同系统”服务端的功能范围、业务规则与验收口径。备注：本文档聚焦服务端能力，不包含教师端本地 UI、悬浮球、画笔等桌面交互实现细节。

---

## 0. 术语与缩写

| 术语 | 解释 |
| --- | --- |
| 服务端 | 为教师管理端、课堂端、课堂互动设备和运营管理中台提供认证、数据、实时互动、AI 能力、报表等服务的后台系统 |
| 运营管理中台 | 管理员使用的后台管理入口，用于账号授权、学校基础数据、系统参数、审计与运维治理 |
| 教师管理端 | 教师使用的课前课后工作区，主要请求班级、设备、报表、资源等管理类接口 |
| 课堂端 | 教师授课使用的课堂工作区，主要请求课次、发题、统计回传、测验、AI 问答等实时接口 |
| 学生账号/答题器 | 与学生账号绑定的答题器/应答器设备，当前不作为独立产品端 |
| 课次 | 一次上课过程的服务端业务会话，承载课堂内所有互动、测验、设备状态与报表数据 |
| 互动任务 | 服务端下发到课堂互动设备的活动单元，如选择题、表达题、点读评测、测验等 |
| ASR | Automatic Speech Recognition，语音转文字 |
| TTS | Text-to-Speech，文本转语音 |
| AI 评分 | 服务端调用算法/模型对语音或文本内容进行自动评价并输出分数与改进指引 |
| WS 通道 | WebSocket 或等效实时长连接通道，用于题目下发、状态同步、统计推送 |
| 导出任务 | 服务端异步生成报表文件的后台任务 |
| 配置中心 | 服务端统一维护的参数、规则、开关、学科能力配置管理模块 |

## 1. 产品背景与目标

### 1.1 背景

教师端 需求清单 已明确课堂教学需要通过“教师端主控 + 学生账号绑定的答题器 + AI 能力”实现课堂互动、测验、语音评测、数据沉淀与报表导出。为支撑教师端稳定运行，服务端需提供统一的数据管理、权限控制、实时互动、AI 能力调度、报表生成与系统运维能力。

### 1.2 产品目标

1. **支撑课堂实时互动闭环**：支持题目下发、学生作答、实时统计、结果归档。
2. **沉淀完整教学数据资产**：统一管理班级、课次、设备、语音、报表、AI 结果等数据。
3. **提供可扩展的能力中台**：支持词典、ASR、TTS、AI 评分、AI 问答、测验等能力接入。
4. **保障服务稳定与安全**：通过权限、日志、监控、恢复机制保障课堂可用性与数据安全。
5. **支持按学科差异化配置**：基于学科控制功能开关、题型能力、词库和评分策略。
6. **支持学校维度隔离与共享教学准备能力**：在同校范围内支持班级、教师、教室关系维护与教学准备数据流转。

## 2. 用户与使用场景

### 2.1 用户角色

1. **管理员**

   - 通过运营管理中台配置账号、权限、学校基础数据、学科能力与系统参数

2. **教师**

   - 通过教师管理端完成同校范围内的班级/学生/教室等教学准备数据初始化、设备/报表/资源管理，并通过课堂端完成进入课堂、发起互动、查看实时统计

3. **学生**

   - 通过与学生账号绑定的答题器参与接收任务、选择作答、语音录制和跟读评测

4. **运维/实施人员**

   - 处理设备异常、服务异常、日志排查、配置发布

### 2.2 典型场景

- 场景 A：教师登录 → 创建班级/导入学生/绑定教室 → 进入教室并选择班级 → 服务端创建课次 → 同步班级学生名单与设备状态 → 发起选择题 → 学生提交 → 服务端实时统计并推送教师端 → 生成报表
- 场景 B：表达题课堂 → 学生录音上传 → 服务端转写 + AI 评分 → 教师端查看排序、回放、评语
- 场景 C：点读/评测 → 教师端框选文本 → 服务端调用词典/TTS/评测服务 → 学生跟读 → 返回评分结果 → 记录归档
- 场景 D：阶段测验 → 导入试卷模板 → 发起测验 → 服务端控制时长、接收答案、自动评分 → 生成个人/班级报告
- 场景 E：AI 问答 → 学生提问语音上传 → 服务端转写聚合问题 → 教师选择问题 → AI 生成回答并归档课次总结

## 3. 产品范围（Scope）

### 3.1 本期包含（Must Have）

- 认证与账号体系（登录、令牌、重置密码、账号锁定）
- 角色与权限控制（管理员/教师/学生、学科权限、导出权限）
- 班级、学生、教室、课次等基础数据管理
- 设备在线状态、绑定关系、刷新/解绑/休眠等状态同步
- 实时互动服务（选择题、表达题、点读评测、测验）
- 语音能力接入（录音上传、ASR、TTS、AI 评分）
- AI 问答与课堂总结
- 词典与翻译查询服务
- 报表生成、预览、导出
- 文件与资源存储
- 配置中心、日志审计、监控告警

### 3.2 暂不包含（Out of Scope）

- 多租户 SaaS 架构
- 第三方统一身份认证（SSO）
- 复杂资源商城、题库运营平台
- 服务端直接接管教师端本地课件渲染与本地外设驱动
- 大规模推荐系统或高级教学画像引擎（如长期成长分析）

## 4. 信息架构与整体交互

### 4.1 服务端总体结构

服务端由以下能力模块组成：

1. **认证与权限中心**
2. **基础数据中心**
3. **课堂会话（课次）中心**
4. **实时互动引擎**
5. **设备与在线状态服务**
6. **语音与 AI 能力服务**
7. **词典/翻译/评测服务**
8. **测验与试卷服务**
9. **报表与导出中心**
10. **文件资源服务**
11. **配置中心**
12. **日志审计与监控中心**

### 4.2 消费端边界

服务端需明确区分不同消费端的接口诉求，避免将“教师管理操作”和“课堂实时操作”混写：

- **教师管理端接口**：班级管理、设备管理、报表中心、资源/素材管理、个人设置
- **课堂端接口**：进入课堂、课次恢复、发题、收答、实时统计、测验、AI 问答、课堂结束
- **运营管理中台接口**：账号授权、学校级配置、系统参数、审计日志、运维监控
- **学生作答链路接口**：提交答案、录音、跟读结果、设备状态

### 4.3 总体业务流

1. 教师管理端登录后获取用户信息、角色权限、学科能力与数据范围。
2. 教师在教师管理端完成班级、设备和资源准备，点击“进入课堂”后切到课堂端。
3. 课堂端请求服务端创建课次并加载班级、学生、设备状态。
4. 课堂端发起互动任务，服务端通过实时通道下发到课堂互动设备。
5. 课堂互动设备回传答案、录音或状态，服务端完成统计、转写、评分或 AI 处理。
6. 教师管理端回看课次结果并触发 Excel 导出；课次结束后服务端汇总数据生成记录、报表与课堂总结。

### 4.4 服务端关键设计原则

- **课次为核心上下文**：课堂内所有互动、录音、评分、设备状态、报表均归属于课次
- **实时与落库分离**：实时统计优先写缓存/消息通道，最终结果落库
- **异步任务解耦**：转写、评分、报表导出、AI 总结等采用异步任务机制
- **能力可配置**：不同学校/学科/角色可通过配置中心控制开关
- **学校维度隔离**：学校作为基础数据与权限边界，同校内共享教学准备数据，跨学校严格隔离
- **可追溯可恢复**：关键业务操作需有日志、状态机与失败恢复机制

## 5. 角色权限

> 说明：服务端按“角色权限 + 工作区 + 学科能力 + 数据范围”四层控制访问能力。

### 5.1 权限原则

1. **最小权限**：默认仅开放角色必需功能。
2. **工作区隔离**：课堂端接口与教师管理端接口隔离鉴权，防止课堂链路调用管理级动作。
3. **数据隔离**：学校作为基础数据隔离边界；教师仅能访问同校范围内的教学准备数据，以及本人可见班级、课次、学生和结果数据。
4. **能力按学科开放**：如英语开放语音评测，语文开放笔画/朗读增强。
5. **高风险操作受控**：导出、删除、批量处理、配置变更必须授权并记录审计日志。
6. **教室共享查看 + 受限编辑**：同校教师可查看、创建、进入、离开教室；教室归档等敏感操作按规则受限。

### 5.2 操作级权限矩阵

| 角色 | 工作区 / 消费端 | 模块 | 查看 | 创建/发起 | 编辑/处理 | 删除/结束 | 导出/配置 | 备注 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 管理员 | 运营管理中台 | 用户/角色授权 | ✓ | ✓ | ✓ | ✓ | ✓ | 全局范围 |
| 管理员 | 运营管理中台 | 配置中心 / 审计 / 运维 | ✓ | ✓ | ✓ | - | ✓ | 全局范围 |
| 教师 | 教师管理端 | 班级 / 学生 / 教室 / 设备管理 | ✓ | ✓ | ✓ | ✓（按规则） | Excel 导入/导出 | 同校范围内教学准备数据 |
| 教师 | 教师管理端 | 报表中心 / 资源中心 | ✓ | - | 预览 / 回看 / 下载 | - | Excel 导出 | 仅本人或授权课次 |
| 教师 | 课堂端 | 教室与课次管理 | ✓ | 创建 / 恢复课次 | 切换课堂状态 | 结束课次 | - | 当前课次范围 |
| 教师 | 课堂端 | 互动 / 测验 / AI 问答 | ✓ | ✓ | 讲评 / 追问 / 回看 | 结束题目 / 结束测验 | - | 受学科开关控制 |
| 学生 | 学生作答链路 | 提交作答 / 录音 / 跟读 | 查看本人提交状态 | ✓ | 重提（按规则） | - | - | 仅本人数据 |

## 6. 功能需求（模块级）

# 6.1 认证与账号模块

## 6.1.1 功能概述

服务端需提供管理员、教师和学生账号的统一认证能力，包括登录、续期、密码重置、账号锁定与退出登录。

## 6.1.2 服务职责

### （1）登录认证

- 支持账号密码登录
- 校验账号状态、角色、权限
- 生成访问令牌与刷新机制
- 支持自动登录所需的续期逻辑

### （2）密码重置

- 支持手机号或邮箱验证码校验
- 支持重置密码并使旧令牌失效

### （3）账号安全控制

- 登录失败次数限制
- 锁定策略配置
- 登录日志记录
- 多端登录策略控制

## 6.1.3 业务规则

- 密码错误连续 5 次触发锁定，锁定时长为 30 分钟
- 不向客户端暴露“账号是否存在”的差异信息
- 刷新令牌过期后需重新登录
- 密码重置后需强制所有旧会话失效
- 同账号多端登录策略采用“新登录踢下旧登录”

## 6.1.4 异常与提示

- 账号或密码错误
- 账号已锁定
- 验证码错误或已失效
- 令牌失效
- 网络异常/认证服务异常

## 6.1.5 验收标准

- 正确账号密码可成功登录并返回权限信息
- 错误密码达到阈值后账号被锁定
- 密码重置后旧登录态不可继续使用
- 自动登录续期逻辑符合设定且过期后要求重新登录

# 6.2 服务主框架（服务治理）

## 6.2.1 功能概述

服务端主框架用于承载所有业务能力，对外统一提供 API、实时通道、异步任务处理与统一鉴权、限流、日志、监控能力。

## 6.2.2 服务职责

- 对外暴露统一网关/API
- 提供 WebSocket 或等效实时连接能力
- 支持同步接口与异步任务双模型
- 提供统一鉴权、限流、幂等、链路日志
- 支持服务注册发现与配置下发（如采用微服务架构）

## 6.2.3 关键交互规则

- 优先保障课堂实时链路：互动下发、作答接收、统计推送优先级高于报表导出
- 耗时型任务异步化：ASR、TTS、AI 评分、AI 总结、报表导出
- 所有关键写操作支持幂等控制
- 所有改变课堂状态的请求需记录操作日志
- 服务异常时需支持降级：如评分失败则至少保存录音与转写结果

## 6.2.4 验收标准

- 教师端及课堂互动链路均需通过统一鉴权调用服务
- WS 通道能稳定建立并支持课次内广播/点对点推送
- 耗时任务不阻塞主交互接口
- 核心链路具备日志可追踪性

# 6.3 基础数据管理模块

## 6.3.1 功能概述

服务端负责管理教师、学生、班级、教室等基础数据，并为课堂会话、设备绑定、互动记录、报表统计提供数据基础。

## 6.3.2 服务职责

### （1）班级管理

- 班级新增、编辑、删除、查询
- 班级与学校、学科、年级关联
- 班级与一位或多位教师关联
- 班级与一个或多个教室关联

### （2）学生管理

- 学生新增、编辑、删除、查询
- Excel 模板导入
- 批量导出

### （3）教室管理

- 教室新增、编辑、查询、归档
- 教室与学校归属绑定
- 教室与多个班级绑定
- 教室当前状态维护
- 教室关联教师状态维护

### （4）教师资料管理

- 教师本人资料查询与编辑
- 教师资料与学校、学科归属关联

## 6.3.3 业务规则

- 导入学生时需校验学号重复、空姓名、非法字符
- 学校作为基础数据隔离边界，不同学校教师不可访问他校班级、学生、教室
- 同一班级可关联一位或多位教师
- 一个教室可关联多个班级，进入课堂时需明确当前班级
- 同校教师可查看、创建、进入、离开教室，并维护班级与教室关系
- 教室删除按归档处理，仅当教室未关联教师时允许归档
- 删除班级时，如已存在课次历史数据，默认不删除历史数据
- 教室在“上课中”状态时不可被其他教师重复占用
- 教师仅可维护本人教师资料，不创建其他教师账号，不配置教师权限

## 6.3.4 异常与提示

- 导入模板格式错误
- 学号重复
- 数据不存在
- 权限不足
- 教室状态冲突
- 教室归档条件不满足

## 6.3.5 验收标准

- 可创建、编辑、删除、查询班级/学生/教室
- 同一班级可关联多位教师并正确回显
- 一个教室可绑定多个班级，并按规则执行归档
- Excel 导入能正确识别成功与失败行
- 删除班级后历史课次数据仍可查询（默认策略）
- 教师只能查看同校范围内教学准备数据与本人权限范围内授课数据

# 6.4 课次管理模块

## 6.4.1 功能概述

课次是服务端课堂业务主线。教师进入教室后，服务端创建课次并将后续所有互动、测验、设备状态、AI 问答与报表统一归档到课次下。

## 6.4.2 服务职责

- 创建课次
- 结束课次
- 记录课次状态变化
- 绑定班级、教室、教师、学科
- 恢复中断课次上下文
- 提供课次查询与归档能力

## 6.4.3 业务规则

- 一名教师同一时刻仅允许存在一个进行中的主课次
- 同一教室同一时刻仅允许一个进行中的课次
- 进入课堂前需校验所选班级已与教室建立关联
- 课次开始后生成唯一课次 ID，后续任务均必须关联此课次
- 异常退出时可将课次标记为“中断”，允许恢复
- 课次结束后不允许继续新增课堂互动，但允许查看与导出数据

## 6.4.4 异常与提示

- 教室已被占用
- 课次不存在
- 课次状态非法
- 恢复失败

## 6.4.5 验收标准

- 教师进入课堂后服务端成功创建课次
- 课次内所有互动与资源均可正确归档
- 中断后可恢复有效上下文
- 结束课次后可查询该课次所有记录

# 6.5 设备与在线状态管理模块

## 6.5.1 功能概述

服务端负责维护学生账号与答题器设备的绑定关系、在线状态、心跳状态、异常状态与课堂内状态同步，为教师端设备管理页面提供数据支持。

## 6.5.2 服务职责

- 设备注册与识别
- 设备与学生绑定/解绑
- 在线状态同步
- 心跳接收与超时判定
- 休眠、刷新等操作记录
- 设备异常状态记录

## 6.5.3 详细需求

- 支持记录设备是否在线
- 支持记录最近心跳时间
- 支持记录设备型号、版本、电量（如可获取）

### （2）学生绑定状态

- 支持按课次/班级返回学生在线名单
- 支持学生机绑定到具体学生
- 支持解绑后刷新状态同步

### （3）课堂设备操作

- 支持教师端触发设备解绑
- 支持教师端触发批量休眠
- 支持刷新连接状态
- 支持异常设备标记与修复指引

## 6.5.4 业务规则

- 超过 30 秒未收到心跳则标记为离线
- 设备解绑后该学生机不可继续提交课堂作答
- 休眠操作需记录执行结果
- 同一设备不可在同一时刻绑定多个学生
- 同一学生不可在同一课次绑定多个设备

## 6.5.5 异常与提示

- 未检测到设备
- 设备身份冲突
- 设备长时间离线
- 心跳异常
- 休眠失败

## 6.5.6 验收标准

- 服务端能正确维护在线/离线/异常状态
- 解绑、刷新、休眠操作后状态可同步到教师端
- 异常设备能记录错误码并提供处理指引
- 设备与学生的绑定关系可追溯

# 6.6 实时互动服务模块

> 互动服务是课堂核心服务。所有互动任务需关联课次、班级、教师、学生与时间，并支持实时推送、实时统计和结果落库。

## 6.6.1 功能概述

## 6.6.2 服务职责

- 创建互动任务
- 下发任务到课堂互动设备
- 接收学生提交
- 实时统计与推送
- 结束任务与冻结结果
- 数据留存与报表出数

## 6.6.3 业务规则

- 互动任务必须绑定课次
- 任务应有状态机：待发布 / 进行中 / 已截止 / 已归档
- 任务截止后禁止再提交
- 实时统计与最终统计需可区分
- 允许配置是否可改答、是否自动截止、是否仅指定学生可见

## 6.6.4 验收标准

- 教师端发起互动后课堂设备能收到任务
- 学生作答提交后服务端能实时处理并推送统计

## 6.6.5 选择题互动服务

- 校验学生身份、设备状态、任务状态

### 验收标准

### 验收标准

- 服务端能接收录音并保存

## 6.12.3 详细需求

### （1）系统参数

- 密码错误阈值
- 账号锁定时长
- 设备离线超时时间
- 课次自动恢复策略
- 导出命名规则

### （2）学科能力配置

- 语文学科是否开放笔画/词典增强
- 英语学科是否开放口语评分/跟读
- 各学科可见模块配置
- 各学科题型可用范围

### （3）AI 与评分配置

- AI 问答功能开关
- ASR/TTS 服务开关或服务商配置
- AI 评分维度与权重
- 文本长度限制与任务并发限制

## 6.12.4 业务规则

- 配置变更需记录操作日志
- 高风险配置变更需管理员权限
- 运行中课次的关键配置不实时生效，从下一课次开始生效

## 6.12.5 验收标准

- 管理员可修改配置并生效
- 客户端可获取初始化配置
- 配置变更有日志可追踪
- 学科差异化能力展示符合配置结果

# 6.13 日志审计与监控模块

## 6.13.1 功能概述

服务端需提供业务日志、操作日志、审计日志、异常监控、性能监控与告警能力，为问题排查和安全追踪提供支撑。

## 6.13.2 服务职责

- 记录关键业务日志
- 记录操作日志与审计日志
- 采集接口耗时、错误率、任务失败率
- 监控实时消息通道与异步任务
- 支持告警通知

## 6.13.3 详细需求

### （1）操作日志

需记录：

- 登录/退出
- 班级新增/删除
- 设备解绑/休眠
- 发题/结束题目
- 发起测验/结束测验
- 导出报表
- 配置修改

### （2）审计日志

需记录：

- 账号权限变更
- 配置中心关键参数变更
- 批量删除/导出
- 高风险数据操作

### （3）日志字段字典

每条操作日志或审计日志至少包含：

- `log_type`
- `operator_role`
- `operator_id`
- `workspace`
- `class_id`
- `lesson_id`
- `target_type`
- `target_id`
- `action`
- `result`
- `error_code`
- `error_message`
- `timestamp`
- `trace_id`

### （4）监控与告警

需监控：

- 接口失败率
- WS 连接数与断连率
- ASR/TTS/AI 调用成功率
- 导出任务失败率
- 设备异常率
- 数据库与缓存健康状态

## 6.13.4 业务规则

- 日志保留周期固定为：业务日志 90 天，审计日志 365 天
- 审计日志不可被普通教师删除或修改
- 告警阈值需可配置
- 课堂进行中异常告警应优先处理实时链路问题

## 6.13.5 验收标准

- 关键业务操作均有日志记录
- 管理员可查询审计日志
- 关键服务异常可触发告警
- 可通过日志追溯课堂关键事件链路

## 7. 数据留存与导出（统一要求）

### 7.1 数据留存范围

- 账号与权限数据
- 班级、学生、教室、课次数据
- 设备绑定与在线状态数据
- 互动题目与学生作答数据
- 录音、转写、AI 评分数据
- 点读、跟读、词典、翻译查询记录
- 测验、试卷、成绩、报告数据
- AI 问答与课堂总结
- 报表与导出任务数据
- 日志、审计与配置变更记录

### 7.2 查询维度

- 按课次
- 按班级/教室
- 按教师
- 按学生
- 按题型/模块
- 按时间范围
- 按报表类型
- 按设备状态

### 7.3 导出规范

- 统一字段字典与统计口径
- 统一日期格式、时区、编码
- 文件命名规则统一
- 导出动作需审计记录
- 大数据量导出采用异步任务
- 默认导出格式仅为 Excel
- 统计指标统一采用双口径并存：应到人数、实际作答人数、参与率、正确率（按应到）、正确率（按实答）、未作答人数、缺席人数

## 8. 非功能需求

### 8.1 性能

- 选择题实时统计刷新延迟：≤ 1s
- 课堂实时消息推送延迟：≤ 1s
- 支持单课次并发在线学生数：≥ 200
- 报表导出任务完成时限：100MB 以内文件在 5 分钟内完成

### 8.2 可靠性

- 网络抖动下课堂数据不丢失
- 实时通道断开后可自动重连
- 课次中断后可恢复上下文
- 异步任务失败支持重试与补偿

### 8.3 兼容性

- 支持教师端、课堂互动链路与运营管理中台的一致权限和数据口径
- 适配 Windows 教师端配套服务调用方式
- 适配已接入设备型号的状态上报协议并通过统一接入层处理

### 8.4 安全

- 密码、令牌、敏感配置需安全存储
- 关键接口需鉴权与权限校验
- 导出与下载需控制访问权限
- 审计日志不可篡改
- AI 内容需进行合规过滤

### 8.5 可运维性

- 支持日志检索与链路追踪
- 支持配置热更新，30 秒内生效（运行中课次关键配置除外）
- 支持监控告警与健康检查
- 支持版本发布回滚，10 分钟内恢复到上一稳定版本

## 9. 验收

### 9.1 验收方式

- 功能验收：按本 需求清单 各模块验收标准逐条验证
- 接口验收：接口输入输出、鉴权、异常码、幂等性校验
- 数据验收：落库字段、统计口径、导出内容一致性
- 场景验收：按课堂典型场景 A-E 全链路走通
- 稳定性验收：课堂高并发、断线重连、异常降级验证
