# 里程碑一 教师端 需求清单

## 1. 文档目的

本文档定义智能教学协同系统 `里程碑一` 阶段教师端的正式交付范围、业务规则、验收口径与依赖边界。

运行环境：Windows10、Windows11 桌面客户端。

教师端包含两个工作区：

1. 管理端工作区。
2. 课堂端工作区。

学校管理员与教师都通过教师端登录与使用系统，具体功能按角色授权生效。

## 2. 本阶段交付目标

`里程碑一` 教师端需交付一个可独立商用验收的 Windows 桌面客户端，完成以下闭环：

1. 学校管理员或教师登录客户端并进入教师端管理端工作区。
2. 学校管理员在教师端管理端完成学校日常治理，包括普通教师账号管理、班级管理、学生名单管理、授课关系管理、普通教师权限分配、设备与学生正式绑定维护。
3. 教师在授权范围内完成教学准备、设备检查、进入课堂与授课互动。
4. 教师在课堂中打开本阶段支持的课件文件并进行批注。
5. 教师发起判断题、单选题、多选题互动。
6. 教师查看课堂实时作答数据。
7. 教师在课后按固定口径导出 CSV 报表。

## 3. 本阶段交付范围

### 3.1 核心功能

1. 登录页及自动登录能力。
2. 双工作区架构：管理端工作区与课堂端工作区。
3. 管理端工作区按角色展示模块：
   1. 学校管理员：普通教师账号管理、班级管理、学生名单管理、授课关系管理、权限分配、设备正式绑定管理、设备状态查看、报表导出。
   2. 教师：班级信息查看、设备状态查看、进入课堂、发起互动、报表导出（需导出权限）。
4. 课堂端工作区包含菜单栏、白板区域、互动工具栏、页面工具栏。
5. 基础图形绘制与对象编辑能力。
6. 课堂基础工具：书写、橡皮、文本、计时器。
7. 互动能力：判断题、单选题、多选题。
8. 课件打开格式：PNG、JPG、JPEG、BMP。
9. 设备联动能力：主机连接、设备在线刷新、设备自动分配、按键作答接收。
10. 报表导出能力：作答情况报表、课次汇总报表，导出格式统一为 CSV。

### 3.2 非核心功能

1. Windows 桌面端本地工作区状态管理能力。
2. 多画布本地管理能力：新建、切换、重命名、删除。
3. 场景文件导入导出及图片导出：打开本地场景文件、保存场景文件、导出图片。
4. 素材库能力：素材新增、插入、导入、导出、删除、重置。
5. 编辑辅助能力：缩放、网格、主题切换、视图模式、专注模式、统计面板。

## 4. 用户角色与使用边界

### 4.1 角色定义

| 角色 | 使用入口 | 核心职责 | 不可用能力 |
| --- | --- | --- | --- |
| 平台管理者 | 管理中台 Web 入口 | 跨校治理、学校开通、学校管理员账号治理、跨校审计、跨校覆盖管理 | 不通过教师端授课 |
| 学校管理员 | 教师端客户端（管理端/课堂端） | 学校日常治理主责：普通教师账号管理、班级管理、学生名单管理、授课关系管理、普通教师权限分配、设备正式绑定维护；也可授课 | 不通过管理中台执行平台治理；不能创建或停用学校管理员账号 |
| 教师 | 教师端客户端（管理端/课堂端） | 教学准备、设备检查、进入课堂、发起互动、导出授权报表 | 不可维护学生名单；不可维护授课关系；不可管理普通教师账号；不通过管理中台治理 |
| 学生 | 不直接使用教师端和管理中台 | 无 | 不进入管理入口 |

学校管理员是教师体系中的高权限角色。学校内日常治理由学校管理员主责，平台管理者保留跨校最终覆盖权。

### 4.2 入口边界

1. 管理中台仅允许平台管理者访问。
2. 教师端管理端由学校管理员与教师共用同一页面，按权限显示模块与操作。
3. 教师端课堂端由学校管理员与教师使用，完成授课与互动。
4. 角色越权访问必须被拒绝并提示原因。

## 5. 业务流程

### 5.1 登录与角色生效流程

1. 用户输入账号密码登录教师端。
2. 系统获取并生效角色信息、可见班级、学科权限、导出权限、模块权限。
3. 客户端进入教师端管理端工作区。
4. 系统按角色展示模块与可操作能力。
5. 权限调整在下次登录生效。

### 5.2 学校日常治理流程（学校管理员）

1. 学校管理员登录教师端并进入管理端。
2. 创建、编辑、停用、重置普通教师账号。
3. 创建与维护班级。
4. 导入、创建、编辑、调班学生名单。
5. 维护教师与班级授课关系。
6. 维护普通教师的可见班级、学科、导出权限、模块权限。
7. 维护设备与学生正式绑定关系。
8. 保存后写入统一审计。

### 5.3 教学准备与授课流程（教师/学校管理员）

1. 教师在管理端选择授课班级并查看设备在线状态。
2. 教师插入设备主机并完成设备连接。
3. 教师切换目标班级，系统自动执行设备分配。
4. 教师点击进入课堂。
5. 系统仅校验教师是否具备该班级授课关系。
6. 进入课堂后可进行白板授课与互动。
7. 课堂结束后返回管理端进行报表导出与回看。

### 5.4 切班自动分配流程

设备候选来源定义：

1. 自动分配候选设备仅包含“学校设备池内且当前会话已感知并在线”的设备。
2. 设备池外设备不进入自动分配流程，仅记录告警事件。

流程规则：

1. 触发条件：设备主机已接入，且系统检测到候选设备；教师切换班级时立即触发。
2. 若目标班级存在正式绑定：
   1. 系统仅自动分配“原绑定且当前在线”的候选设备。
   2. 原绑定但未连接的学生保持未分配。
   3. 系统不使用其他设备进行自动替代。
3. 若目标班级不存在正式绑定：
   1. 系统从当前候选设备中“已在线且未占用”的设备自动分配给班级学生。
   2. 分配结果仅本次会话有效，不写回正式绑定。
4. 设备不足时：
   1. 系统执行部分分配。
   2. 未分配学生显示为未分配状态，并提供名单提示。
5. 回收规则：
   1. 切换到其他班级时，当前班级临时分配映射自动回收。
   2. 设备主机断开时，当前会话临时分配映射自动回收。

### 5.5 课后回看流程

1. 教师返回管理端。
2. 按课次、日期、班级筛选记录。
3. 选择报表类型并导出 CSV。

## 6. 模块功能需求

### 6.1 登录模块

| 项       | 说明                                                           |
| -------- | -------------------------------------------------------------- |
| 页面入口 | 客户端启动首页                                                 |
| 使用者   | 学校管理员、教师                                               |
| 使用前提 | 账号状态正常                                                   |
| 核心操作 | 输入账号密码，勾选记住密码或自动登录，点击登录                 |
| 成功状态 | 登录成功进入管理端，显示角色与权限范围                         |
| 失败状态 | 账号密码错误、网络异常、角色无入口权限                         |
| 数据保存 | 系统保存登录偏好                                               |
| 验收口径 | 正确账号可登录；错误账号有明确提示；自动登录在登录状态有效期内生效 |

登录页必须包含：

1. 账号输入框。
2. 密码输入框。
3. 记住密码复选项。
4. 自动登录复选项。
5. 登录按钮。
6. 登录状态提示。

权限与模块生效规则：

1. 模块是否显示由角色与模块权限共同决定。
2. 模块显示后，具体操作仍按班级、学科、导出等权限校验。
3. 权限调整在下次登录生效。
4. 用户在当前课次中被停用或降权时，当前课次允许继续，结束后按新权限生效。

### 6.2 管理端工作区框架

教师端管理端采用固定三段结构：

1. 顶部栏：显示工作区名称、姓名、角色、学科。
2. 左侧导航：按权限显示模块入口。
3. 右侧内容区：展示模块页面内容。

导航模块按角色分层：

1. 学校管理员可见：普通教师账号管理、班级管理、学生名单管理、授课关系管理、权限分配、设备正式绑定管理、设备管理、报表导出、个人设置、进入课堂、退出登录。
2. 教师可见：班级查看、设备管理、报表导出（需导出权限）、个人设置、进入课堂、退出登录。

### 6.3 学校治理模块（仅学校管理员）

| 项 | 说明 |
| --- | --- |
| 页面入口 | 管理端工作区 -> 学校治理相关模块 |
| 使用者 | 学校管理员 |
| 使用前提 | 学校管理员已登录且状态正常 |
| 核心操作 | 普通教师账号管理、班级管理、学生名单管理、授课关系维护、普通教师权限分配 |
| 成功状态 | 变更正确保存并可在教师端与审计中追溯 |
| 失败状态 | 字段缺失、重复标识、权限不足、保存失败 |
| 数据保存 | 所有成功/失败/拒绝均写入统一审计 |
| 验收口径 | 学校管理员可完成学校日常治理；教师无对应编辑能力 |

固定规则：

1. 学校管理员可创建、编辑、停用、重置普通教师账号。
2. 学校管理员不可创建或停用学校管理员账号。
3. 学校管理员可创建和维护班级。
4. 学校管理员可导入、创建、编辑、调班学生名单。
5. 学校管理员维护教师与班级授课关系。
6. 教师不能自助加入或移除授课班级。
7. 学校管理员分配普通教师的可见班级、学科权限、导出权限、模块权限。

### 6.4 设备管理与自动分配模块

| 项       | 说明                                                         |
| -------- | ------------------------------------------------------------ |
| 页面入口 | 管理端工作区 -> 设备管理                                     |
| 使用者   | 学校管理员、教师                                             |
| 使用前提 | 设备主机已接入；用户具备目标班级可见或管理权限               |
| 核心操作 | 查看设备在线状态、切换班级触发自动分配、刷新设备池内设备状态 |
| 成功状态 | 设备状态与分配结果正确展示并可追溯                           |
| 失败状态 | 主机未连接、设备接入不可用、状态同步失败                     |
| 数据保存 | 系统记录并可追溯设备状态快照、分配结果、失败原因             |
| 验收口径 | 切班后自动分配规则与临时映射回收规则符合要求                 |

页面必须显示：

1. 设备编号（来源于学校设备池主数据）。
2. 在线状态：在线、离线、异常。
3. 班级分配状态：已分配、未分配。
4. 学生分配状态：已匹配设备、未匹配设备。
5. 电量状态。
6. 信号状态。
7. 操作按钮：刷新设备池内设备状态。

设备状态判定口径：

1. 在线：设备在判定窗口内存在有效连接或状态上报，按平台接收时间判定。
2. 离线：设备超过判定窗口未上报状态，按平台接收时间判定。
3. 异常：设备通信失败或状态读取失败，按失败事件判定。

设备管理固定规则：

1. 设备按学校级设备池管理，不按物理空间固化。
2. 学校管理员可维护设备与学生正式绑定关系。
3. 教师仅可查看与使用自动分配结果，不可维护正式绑定关系。
4. 切换班级后立即触发自动分配。
5. 目标班级存在正式绑定时，仅分配原绑定且当前在线设备。
6. 原绑定但未连接设备不做自动替代，学生保持未分配状态。
7. 目标班级不存在正式绑定时，系统自动生成会话级临时分配。
8. 临时分配不写回正式绑定。
9. 切班或主机断开时，临时分配自动回收。
10. 设备不足允许部分分配，并明确提示未分配学生名单。
11. 自动分配候选设备仅来自学校设备池内且当前会话已感知并在线的设备。
12. 设备池外设备仅记录告警，不纳入自动分配和课堂统计分母。

课堂能力联动规则：

1. 无设备或设备不足不阻止进入课堂。
2. 互动能力仅覆盖已分配设备对应学生。
3. 未分配学生在互动统计中按未参与处理并明确提示。

### 6.5 报表导出模块

| 项       | 说明                                                   |
| -------- | ------------------------------------------------------ |
| 页面入口 | 管理端工作区 -> 报表导出                               |
| 使用者   | 学校管理员、教师（需导出权限）                         |
| 使用前提 | 存在课次记录或互动记录                                 |
| 核心操作 | 筛选记录、选择报表类型、导出报表                       |
| 成功状态 | 导出成功，文件内容与固定口径一致                       |
| 失败状态 | 无记录、导出失败、权限不足                             |
| 数据保存 | 导出行为与筛选条件写入统一审计                         |
| 导出     | 仅支持 CSV                                             |
| 验收口径 | 可导出作答情况报表与课次汇总报表；无权限时拒绝并可追溯 |

筛选维度固定为：

1. 班级。
2. 课次日期。
3. 课次名称。
4. 报表类型。

报表类型固定为：

1. 作答情况报表。
2. 课次汇总报表。

导出命名固定为：

`{班级名称}_{课次日期}_{报表类型}.csv`

### 6.6 课堂端工作区框架

课堂端固定为四区结构：

1. 菜单栏。
2. 白板与课件展示区。
3. 互动工具栏。
4. 页面工具栏。

课堂界面规则：

1. 当前课次名称常驻可见。
2. 当前班级名称常驻可见。
3. 结束课堂按钮常驻可见。
4. 当前题目状态常驻可见。
5. 设备状态提示常驻可见。

进入课堂规则：

1. 仅具备该班级授课关系的用户可进入课堂。
2. 进入课堂只校验授课关系，不以设备完整分配作为硬阻断条件。
3. 无设备或设备不足时允许进入课堂，但互动能力受限且需提示。
4. 进入课堂不校验学科权限；学科权限仅影响课堂内相关功能的展示与可用性。

### 6.7 菜单栏模块

本阶段菜单栏包含：

1. 打开文件。
2. 保存课堂草稿。
3. 返回管理端。
4. 结束课堂。

打开文件支持格式：

1. PNG
2. JPG
3. JPEG
4. BMP

打开失败提示需区分：

1. 文件不存在。
2. 文件损坏。
3. 格式不支持。
4. 文件被占用。
5. 权限不足。

### 6.8 白板区域

白板区域承担课件展示与批注叠加能力。

本阶段必须支持：

1. 多画布本地管理：新建、切换、重命名、删除。
2. 基础绘制工具：选择、矩形、菱形、椭圆、箭头、直线、自由绘制、文本、图片、橡皮。
3. 常用对象编辑：撤销、重做、复制粘贴、删除、锁定、编组、翻转、层级调整、样式复制粘贴。
4. 场景与图片导入导出：打开场景文件、保存场景文件、导出 PNG/SVG、插入本地图片。
5. 素材库能力：加入、插入、导入、导出、删除、重置。
6. 编辑辅助能力：缩放、缩放重置、缩放适配、手型平移、网格、主题、视图模式、专注模式。
7. 统计面板：元素数量、对象坐标尺寸、场景与本地存储占用、版本信息。

批注数据保存规则：

1. 批注与当前课次绑定。
2. 批注按页面保存。
3. 课堂异常退出后，重新进入同一课次可恢复草稿。

### 6.9 互动工具栏

本阶段互动工具栏包含：

1. 书写。
2. 橡皮。
3. 文本。
4. 计时器。
5. 选择题互动。

书写：

1. 颜色：黑、红、蓝、绿。
2. 线宽：细、中、粗。
3. 支持撤销、重做。

橡皮：

1. 擦除当前页批注。
2. 清空当前页批注。

文本：

1. 插入文本框。
2. 字号：16、24、32。
3. 颜色：黑、红、蓝。

计时器：

1. 1、3、5、10 分钟快捷倒计时。
2. 暂停、继续、重置。
3. 倒计时结束本地提示。

选择题互动支持：

1. 判断题（全班作答）。
2. 单选题（全班作答）。
3. 多选题（全班作答）。

创建题目必须配置：

1. 题型。
2. 题干。
3. 选项。
4. 正确答案。
5. 作答模式。
6. 截止时间。
7. 是否允许修改答案。

课堂端必须显示实时信息：

1. 已作答人数。
2. 未作答人数。
3. 未分配人数。
4. 每个选项人数与比例。

实时统计口径：

1. 统计分母与分子基于“班级应到名单 + 当前分配映射 + 已提交作答记录”计算。
2. 已作答人数：当前课次中，分配映射内已提交有效作答的去重学生数。
3. 未作答人数：班级应到名单中已分配设备但未提交有效作答的学生数。
4. 未分配人数：班级应到名单中未匹配设备的学生数。
5. 每个选项人数与比例：基于有效作答记录计算；比例分母为该题有效作答总人数。
6. 课堂统计不以硬件在线总数直接计算。

### 6.10 页面工具栏

本阶段页面工具栏固定为：

1. 新增空白页。
2. 上一页。
3. 当前页码展示。
4. 下一页。
5. 页面缩略预览。

## 7. 数据留存与查询要求

教师端必须提交并可回查以下数据：

1. 登录成功与失败结果。
2. 普通教师账号变更记录（仅学校管理员操作）。
3. 班级创建、编辑与状态变更记录（仅学校管理员操作）。
4. 学生创建、编辑、调班与导入批次记录（仅学校管理员操作）。
5. 授课关系变更记录（仅学校管理员操作）。
6. 进入课堂与结束课堂记录。
7. 设备池内设备在线状态快照（按平台接收时间记录）。
8. 切班自动分配结果、未分配名单、回收事件（按平台接收时间记录）。
9. 设备池外设备事件告警记录（不纳入自动分配与课堂统计分母）。
10. 每道题配置与每位学生提交答案。
11. 导出行为（成功、失败、拒绝）。
12. 每页批注草稿。

设备相关记录口径：

1. 设备状态快照、分配结果与回收事件统一使用平台接收时间作为记录时间。
2. 设备事件归并与查询不依赖硬件原始时间戳排序。

教师端本地需保存：

1. 登录偏好。
2. 当前窗口状态。
3. 当前课次未提交草稿。
4. 最近一次打开文件路径。

共享数据同步规则：

1. 教师端与管理中台对同一业务对象的显示与查询结果应保持一致。
2. 用户重新进入页面或主动刷新后应看到最新数据。
3. 关键操作成功、失败、拒绝均写入统一审计。

## 8. 异常与失败处理

本阶段教师端必须显式处理以下异常：

1. 登录失败：提示账号与密码错误、网络异常。
2. 角色越权：提示“当前账号无权访问该功能”。
3. 学生名单编辑越权：教师尝试编辑时必须拒绝并提示无权限。
4. 授课关系编辑越权：教师尝试编辑时必须拒绝并提示无权限。
5. 设备接入初始化失败：提示设备功能不可用。
6. 主机未连接：设备管理页显示未连接。
7. 切班自动分配失败：提示失败原因并保留上次有效状态。
8. 已绑定设备未连接：对应学生显示未分配，不自动替代。
9. 设备不足：允许部分分配并提示未分配名单。
10. 题目创建失败：不创建本地假成功状态。
11. 实时统计超时：显示“统计更新中”，不得清空已返回数据。
12. 导出失败：显示失败原因并允许重试。
13. 导出被拒绝：明确提示无导出权限并写入审计。
14. 文件损坏或格式不支持：阻止打开并保留当前课堂状态。
15. 课堂中断：重新进入同一课次时恢复未结束状态。
16. 设备池外设备事件：记录告警，不纳入自动分配与课堂统计分母。
17. 设备事件延迟或乱序：按幂等规则与平台接收时间归并处理，统计结果不得因旧事件回退。

## 9. 非功能要求

1. 教师端运行环境固定为 Windows。
2. 客户端异常退出后，同一课次草稿可恢复。
3. 所有导出文件名符合统一命名规则。
4. 所有导出内容中的中文文本应可正常读取。

## 10. 验收标准

1. 学校管理员与教师可通过同一教师端登录并按角色展示不同功能。
2. 学校管理员可创建、编辑、停用、重置普通教师账号。
3. 学校管理员可创建班级并维护学生名单。
4. 学校管理员可维护教师与班级授课关系。
5. 教师仅可查看学生名单，不可增删改学生名单。
6. 教师不可维护授课关系。
7. 学校管理员可维护设备与学生正式绑定关系。
8. 设备主机已接入且存在学校设备池内已感知在线设备时，教师切换班级后系统立即触发自动分配。
9. 自动分配候选设备范围限定为“学校设备池内且当前会话已感知并在线”的设备；设备池外设备不进入自动分配并写入告警记录。
10. 无正式绑定时，系统按候选设备生成会话级临时分配且不写回正式绑定。
11. 有正式绑定时，仅分配原绑定且在线设备；缺失设备不自动替代。
12. 设备不足时允许部分分配并提示未分配名单；切班或主机断开时临时分配自动回收。
13. 仅校验授课关系即可进入课堂；无设备或设备不足不阻断进入课堂。
14. 课堂实时统计按“班级应到名单 + 当前分配映射 + 已提交作答记录”计算，可反映未分配学生状态，不以硬件在线总数直接计算。
15. 教师可发起判断题、单选题、多选题并查看实时统计。
16. 有导出权限的用户可导出报表；无导出权限时被拒绝并写入审计。
17. 课堂异常退出后再次进入可恢复未结束课次。
