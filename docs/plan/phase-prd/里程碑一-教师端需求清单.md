# 里程碑一 教师端 需求清单

## 1. 文档目的

本文档定义智能教学协同系统 `里程碑一` 阶段教师端的正式交付范围、业务规则、验收口径与依赖边界。

运行环境：Windows10，Windows11 桌面客户端。

## 2. 本阶段交付目标

`里程碑一` 教师端需交付一个可独立商用验收的 Windows 桌面客户端，教师在本阶段能够完成以下完整业务闭环：

1. 使用教师账号登录客户端并进入教师工作区。
2. 在教师工作区完成学校内班级、学生、教室等教学准备数据初始化，并维护本人教师资料。
3. 选择班级与教室进入课堂。
4. 在课堂中打开本阶段支持的课件文件并进行批注。
5. 发起判断题、单选题、多选题互动。
6. 查看课堂中的实时作答数据。
7. 在课后按固定口径导出 CSV 报表文件。

## 3. 本阶段交付范围

1. 登录页及自动登录能力。
2. 教师端双工作区架构，包括教师管理工作区和课堂工作区。
3. 教师管理工作区支持班级与学生初始化、教室管理、设备管理、报表导出、个人资料维护等功能；同时在左侧导航底部设置固定操作区，提供“进入课堂”“退出登录”等快捷入口。
4. 课堂工作区包含菜单栏、白板区域、互动工具栏、页面工具栏等核心区域。
5. Windows 桌面端白板编辑器运行框架及本地工作区状态管理。
6. 多画布本地管理能力，包括画布新建、切换、重命名、删除。
7. 基础图形绘制与对象编辑，可使用选择、矩形、菱形、椭圆、箭头、直线、自由绘制、文本、图片、橡皮等工具。
8. 场景文件导入导出及图片导出，包括打开本地场景文件、保存场景文件、导出图片。
9. 素材库相关能力，包括素材新增、插入、导入、导出、删除、重置。
10. 编辑辅助功能，包括缩放、网格、主题切换、视图模式、专注模式、统计面板等。
11. 课堂基础工具，包括书写、橡皮、文本、计时器。
12. 选择题互动能力，包括判断题、单选题、多选题。
13. 本阶段支持打开的课件格式包括 PNG、JPG、JPEG、BMP。
14. 设备联动能力，包括设备连接状态显示、按键作答接收。
15. 报表导出能力，包括作答情况报表、课次汇总报表，导出格式统一为 CSV。

## 4. 用户角色与使用边界

| 角色 | 使用入口 | 可用能力 | 不可用能力 |
| --- | --- | --- | --- |
| 教师 | 教师端客户端 | 登录、班级与学生初始化、教室管理、本人资料维护、设备检查、进入课堂、发起互动、导出报表 | 用户授权、系统配置、审计查询、其他教师账号管理 |
| 管理员 | 不通过教师端执行管理动作 | 无 | 不在教师端进行账号授权与系统治理 |
| 学生 | 不直接使用教师端 | 无 | 不进入教师端界面 |

教师端只承担教师课前准备、授课、课后回看的桌面端职责，不承担管理员治理职责，不承载云端监控与审计查询界面。

## 5. 业务流程

### 5.1 登录到进入课堂流程

1. 教师输入账号密码登录。
2. 客户端请求后端认证服务并获取访问令牌、用户信息、学科权限、可见班级列表。
3. 客户端进入教师管理工作区。
4. 教师在班级与学生初始化或教室管理中完成课前准备，在设备管理中确认设备在线状态。
5. 教师点击“进入课堂”，选择班级、教室和学科。
6. 客户端向后端申请创建课次。
7. 课次创建成功后，客户端切换至课堂工作区。

### 5.2 基础数据初始化流程

1. 教师登录后进入教师管理工作区。
2. 教师在同校范围内创建或编辑班级。
3. 教师手动创建学生账号或通过 `CSV` 导入学生账号。
4. 教师为班级关联一位或多位教师，并绑定一个或多个教室。
5. 教师在个人设置中维护本人教师资料。
6. 系统保存学校范围内的基础数据关系，供进入课堂与报表导出使用。

### 5.3 课堂互动流程

1. 教师在课堂工作区打开课件或空白页。
2. 教师使用书写、橡皮、文本工具进行批注。
3. 教师在互动工具栏创建题目并设置题型、答案、答题模式、截止时间。
4. 客户端通过本地设备接入能力开始题目，并同步通知后端创建互动任务。
5. 学生通过已绑定答题器提交答案。
6. 客户端接收设备接入层回传的按键事件并实时推送给后端。
7. 后端返回统计结果，客户端实时刷新人数与结果列表。
8. 教师结束题目，客户端关闭题目状态并保存互动记录。

### 5.4 课后回看流程

1. 教师返回教师管理工作区。
2. 教师进入报表导出页，按课次、日期、班级筛选记录。
3. 教师选择作答情况报表或课次汇总报表。
4. 教师点击导出，生成并下载 CSV 文件。

## 6. 模块功能需求

### 6.1 登录模块

| 项       | 说明                                                             |
| -------- | ---------------------------------------------------------------- |
| 页面入口 | 客户端启动首页                                                   |
| 使用者   | 教师                                                             |
| 使用前提 | 已由管理中台分配教师账号且账号状态正常                           |
| 核心操作 | 输入账号、密码，勾选记住密码或自动登录，点击登录                 |
| 成功状态 | 登录成功后进入教师管理工作区，显示教师姓名、学科权限、可见班级   |
| 失败状态 | 账号与密码组合不存在、网络异常、权限不足                         |
| 数据保存 | 本地保存登录偏好；令牌按安全策略存储                             |
| 导出     | 不涉及                                                           |
| 验收口径 | 正确账号可登录，错误账号有明确提示，自动登录可在令牌有效期内生效 |

登录页必须包含以下元素：

1. 账号输入框。
2. 密码输入框。
3. 记住密码复选项。
4. 自动登录复选项。
5. 登录按钮。
6. 登录状态（包含失败）提示。

登录相关状态通过 toast 展示。

### 6.2 教师管理工作区框架

教师管理工作区采用固定三段结构：

1. 顶部栏：显示工作区名称、教师姓名、学科。
2. 左侧导航：班级与学生初始化、教室管理、设备管理、报表导出、个人设置、进入课堂、退出登录。
3. 右侧内容区：展示对应模块页面内容。

教师在未进入课堂前允许自由切换模块；进入课堂后默认切换到课堂工作区。

### 6.3 班级、学生与教室初始化模块

| 项 | 说明 |
| --- | --- |
| 页面入口 | 教师管理工作区 -> 班级与学生初始化 / 教室管理 |
| 使用者 | 教师 |
| 使用前提 | 教师已登录且具备同校范围内教学准备数据维护权限 |
| 核心操作 | 创建或编辑班级、创建或导入学生账号、关联教师、绑定教室、按班级进入课堂 |
| 成功状态 | 班级、学生、教师关联和教室关联正确展示并保存 |
| 失败状态 | 导入模板错误、字段缺失、重复学号、班级不存在、教室状态不允许操作 |
| 数据保存 | 导入成功与失败记录保存至后端 |
| 导出 | 不涉及 |
| 验收口径 | 教师可完成班级基础数据维护、学生账号创建或导入，并查看失败原因 |

班级与学生初始化页面必须包含：

1. 班级列表区：显示班级名称、年级、学科、任课教师列表、关联教室列表、学生人数。
2. 学生明细区：显示学生姓名、学号、绑定设备号、状态。
3. 学生初始化区：支持手动创建学生账号和上传 `CSV` 学生名单文件。
4. 关联设置区：支持为班级关联一位或多位教师，并绑定一个或多个教室。
5. 教室列表区：显示教室名称、关联班级数、关联教师状态、当前状态、进入/离开/归档动作。
6. 进入课堂按钮。

学生导入规则固定如下：

1. 支持手动创建学生账号和 `CSV` 模板导入。
2. 必填字段：学生姓名、学号、所属班级。
3. 可选字段：性别、座号、设备编号。
4. 同一班级内学号不得重复。
5. 导入失败时必须返回逐行失败原因。

班级与教室关系规则固定如下：

1. 同一班级可关联一位或多位教师。
2. 一个教室可关联多个班级，进入课堂时由教师选择当前班级。
3. 同校教师可查看、创建、进入、离开教室，并维护教室与班级的关联关系。
4. 教室删除按归档处理，仅当教室未关联教师时允许归档。
5. 教师端不创建其他教师账号，不配置教师权限，不维护跨学校数据。

本人教师资料维护由个人设置承担，仅支持维护本人姓名、学科、联系方式等教师基础资料。

### 6.4 设备管理模块

| 项       | 说明                                                         |
| -------- | ------------------------------------------------------------ |
| 页面入口 | 教师管理工作区 -> 设备管理                                   |
| 使用者   | 教师                                                         |
| 使用前提 | 设备接入能力可用，接收器已连接，教师具备对应班级可见权限     |
| 核心操作 | 查看在线状态                                                 |
| 成功状态 | 设备状态与后端记录一致，教师可确认进入课堂条件               |
| 失败状态 | 设备接入能力不可用、接收器未连接、设备断开、状态同步失败     |
| 数据保存 | 设备在线状态保存至后端                                       |
| 导出     | 不涉及                                                       |
| 验收口径 | 教师可在进入课堂前看到设备在线列表                           |

设备管理页面必须显示：

1. 设备编号。
2. 学生姓名。
3. 在线状态：在线、离线、异常。
4. 电量状态。
5. 信号状态。
本阶段设备交互边界如下：

1. 教师端需通过可维护的设备接入层完成设备连接、状态读取和课堂控制。
2. 设备接入方案可采用团队选定的可维护实现，只要满足课堂能力要求。
3. 进入课堂前必须完成设备会话初始化或等效准备动作，才能发起题目。
4. 后端与设备接入实现解耦，只接收标准化后的业务事件和状态数据。
5. 教师端负责采集并同步连接事件、按键事件、设备状态事件等课堂所需数据。

### 6.5 报表导出模块

| 项 | 说明 |
| --- | --- |
| 页面入口 | 教师管理工作区 -> 报表导出 |
| 使用者 | 教师 |
| 使用前提 | 已存在课次记录或互动记录 |
| 核心操作 | 筛选记录、选择报表类型、导出报表 |
| 成功状态 | 导出成功，文件内容与固定口径一致 |
| 失败状态 | 无记录、导出任务失败、下载失败、权限不足 |
| 数据保存 | 导出记录和筛选条件保存到后端审计记录 |
| 导出 | 仅支持 CSV |
| 验收口径 | 可导出作答情况报表与课次汇总报表，字段完整，导出内容中的文本字段统一按 UTF-8 编码规范处理 |

筛选维度固定为：

1. 班级。
2. 课次日期。
3. 课次名称。
4. 报表类型。

本阶段报表类型固定为：

1. 作答情况报表。
2. 课次汇总报表。

作答情况报表字段固定为：

1. 课次 ID。
2. 题目 ID。
3. 题型。
4. 题干摘要。
5. 正确答案。
6. 应到人数。
7. 实答人数。
8. 参与率。
9. 正确人数。
10. 正确率（按应到）。
11. 正确率（按实答）。
12. 未作答人数。
13. 缺席人数。
14. 选项分布。
15. 开始时间。
16. 结束时间。
17. 用时。

课次汇总报表字段固定为：

1. 课次 ID。
2. 班级名称。
3. 教师姓名。
4. 互动次数。
5. 应到人数。
6. 实答人数。
7. 参与率。
8. 平均正确率（按应到）。
9. 平均正确率（按实答）。
10. 导出时间。

导出命名固定为：

`{班级名称}_{课次日期}_{报表类型}.csv`

### 6.6 课堂工作区框架

课堂工作区固定为四区结构：

1. 菜单栏。
2. 白板与课件展示区。
3. 互动工具栏。
4. 页面工具栏。

课堂进行中教师端必须满足以下界面规则：

1. 当前课次名称常驻可见。
2. 当前班级名称常驻可见。
3. 结束课堂按钮常驻可见。
4. 当前题目状态常驻可见。
5. 设备连接异常提示可见。

### 6.7 菜单栏模块

本阶段菜单栏仅包含以下动作：

1. 打开文件。
2. 保存课堂草稿。
3. 返回教师工作区。
4. 结束课堂。

打开文件只支持以下格式：

1. `PNG`
2. `JPG`
3. `JPEG`
4. `BMP`

打开失败提示必须区分：

1. 文件不存在。
2. 文件损坏。
3. 格式不支持。
4. 文件被占用。
5. 权限不足。

### 6.8 白板区域

白板区域承担课件展示与批注叠加能力。

本阶段必须支持：

1. 多画布本地管理：支持新建画布、切换画布、重命名当前画布、删除画布。
2. 基础图形与绘制工具：支持选择、矩形、菱形、椭圆、箭头、直线、自由绘制、文本、图片、橡皮。
3. 常用对象编辑动作：支持撤销、重做、复制粘贴、删除、锁定、编组、翻转、层级调整、样式复制粘贴。
4. 场景与图片导入导出：支持打开本地场景文件、保存场景文件、导出 `PNG`、`SVG` 图片，以及插入本地图片。
5. 素材库能力：支持将图形加入素材库、从素材库插入图形、导入素材库文件、导出素材库文件、删除素材、重置素材库。
6. 编辑辅助能力：支持缩放、缩放重置、缩放适配、手型平移、网格显示、主题切换、视图模式、专注模式。
7. 统计面板能力：支持查看场景元素数量、选中对象坐标与尺寸、场景与本地存储占用、版本信息等辅助数据。

批注数据保存规则：

1. 批注与当前课次绑定。
2. 批注按页面保存。
3. 课堂异常退出后，重新进入同一课次可恢复草稿状态。

### 6.9 互动工具栏

本阶段互动工具栏仅包含以下工具：

1. 书写。
2. 橡皮。
3. 文本。
4. 计时器。
5. 选择题互动。

#### 6.9.1 书写

1. 支持颜色选择：黑、红、蓝、绿。
2. 支持线宽选择：细、中、粗。
3. 支持撤销、重做。

#### 6.9.2 橡皮

1. 支持擦除当前页批注。
2. 支持清空当前页批注。

#### 6.9.3 文本

1. 支持插入文本框。
2. 支持修改字号： 16、24、32。
3. 支持修改颜色：黑、红、蓝。

#### 6.9.4 计时器

1. 支持 `1`、`3`、`5`、`10` 分钟快捷倒计时。
2. 支持暂停、继续、重置。
3. 倒计时结束时本地弹出提示，不向设备发送语音或震动控制。

#### 6.9.5 选择题互动

本阶段正式支持的题型与模式如下：

| 题型   | 模式                         |
| ------ | ---------------------------- |
| 判断题 | 全班作答 |
| 单选题 | 全班作答 |
| 多选题 | 全班作答 |

创建题目时必须配置：

1. 题型。
2. 题干。
3. 选项。
4. 正确答案。
5. 作答模式。
6. 截止时间。
7. 是否允许修改答案。

课堂端必须显示以下实时信息：

1. 已作答人数。
2. 未作答人数。
3. 缺席人数。
4. 每个选项人数和比例。

### 6.10 页面工具栏

本阶段页面工具栏固定为：

1. 新增空白页。
2. 上一页。
3. 当前页码展示。
4. 下一页。
5. 页面缩略预览。

## 7. 数据留存与查询要求

教师端必须向后端提交并可回查以下数据：

1. 登录成功与失败结果。
2. 班级进入课堂记录。
3. 课次开始与结束时间。
4. 设备在线状态快照。
5. 每道题的题目配置。
6. 每个学生的提交答案。
7. 每次导出行为。
8. 每页批注草稿。

教师端本地需保存：

1. 登录偏好。
2. 当前窗口状态。
3. 当前课次未提交草稿。
4. 最近一次打开文件路径。

## 8. 异常与失败处理

本阶段教师端必须显式处理以下异常：

1. 登录失败：明确提示账号与密码组合不存在、网络异常。
2. 权限不足：提示“当前账号无权访问该班级或该模块”。
3. 设备接入能力初始化失败：提示设备功能不可用，禁止进入需要设备联动的课堂互动。
4. 设备未连接：设备管理页明确显示“未连接”，进入课堂时弹出确认。
5. 设备状态异常：不允许隐藏异常。
6. 题目创建失败：不创建本地假成功状态。
7. 实时统计超时：显示“统计更新中”，不得清空已返回数据。
8. 导出失败：显示失败原因并允许重新发起。
9. 文件损坏或格式不支持：阻止打开并保留当前课堂状态。
10. 课堂中断：下次重新进入同一课次时恢复到上次未结束状态。

## 9. 非功能要求

1. 教师端运行环境固定为 Windows。
2. 客户端异常退出后，同一课次草稿可恢复。
3. 所有导出文件名必须符合统一命名规则。
4. 所有导出内容中的文本字段统一按 UTF-8 编码规范处理。
5. 若设备或操作系统版本过旧，或系统字符集配置异常，不保证所有环境中的展示结果均可完全避免乱码。

## 10. 验收标准

1. 教师可使用分配账号登录并进入教师管理工作区。
2. 教师可创建班级、创建或导入学生账号，并查看失败原因。
3. 教师可在设备管理页看到在线设备、电量和信号。
4. 教师可维护班级与教师、班级与教室关联关系，并管理同校范围内教室。
5. 教师可维护本人教师资料。
6. 教师可创建课次并进入课堂。
7. 教师可在客户端中创建、切换、重命名和删除多个本地画布。
8. 教师可使用选择、矩形、菱形、椭圆、箭头、直线、自由绘制、文本、图片、橡皮等基础白板工具。
9. 教师可打开本地场景文件、保存场景文件，并导出 `PNG`、`SVG` 图片。
10. 教师可使用素材库完成素材加入、插入、导入、导出、删除与重置。
11. 教师可使用缩放、网格、主题切换、视图模式、专注模式、统计面板等编辑辅助功能。
12. 教师可打开 `PNG`、`JPG`、`JPEG`、`BMP` 文件。
13. 教师可使用书写、橡皮、文本、计时器工具。
14. 教师可发起判断题、单选题、多选题。
15. 学生通过答题器提交答案后，教师端统计结果实时更新。
16. 教师可在报表导出页导出作答情况报表和课次汇总报表。
17. 课堂异常退出后再次进入，可恢复未结束课次。

## 11. UI 交付说明

1. 对于有定制风格、特殊布局或关键交互要求的页面，需提供对应的 UI 线稿、原型或页面示意作为实现依据。
2. 当前未提供完整 UI 线稿或示意的页面，默认按行业通用规范、常规交互方式和项目既有风格进行设计与实现。
3. 颜色、字号、字重、间距等简单样式调整可在开发过程中配合修改。
4. 涉及页面结构、布局、信息层级或交互逻辑的调整，视为需求变更，需重新评估范围、排期与成本。

## 12. 依赖与前置条件

1. 管理中台已完成教师账号、班级、学生、教室基础数据初始化。
2. 后端已提供认证、课次、设备、互动、报表接口。
3. 教师端运行设备已具备首期接入设备所需的运行依赖。
4. 教师端能够访问云端后端服务。

## 13. 风险提示

1. 本地 Windows 环境对设备接入依赖、驱动和杀毒策略较敏感。
2. 设备接收器未连接时，课堂互动无法完成完整验收。
3. 学校网络波动会直接影响实时统计刷新体验。
4. 课件文件过大可能影响首次打开时间。
