# 里程碑二 教师端 需求清单

## 1. 文档目的

本文档定义智能教学协同系统 `里程碑二` 阶段教师端新增交付内容的正式范围、业务规则、验收标准与依赖边界。

运行环境：Windows10，Windows11 桌面客户端。。

## 2. 本阶段交付目标

`里程碑二` 教师端需在已上线课堂基础链路上交付语言类课堂能力和轻量资源能力，使教师在本阶段能够完成以下新增业务闭环：

1. 在课堂中发起表达题并接收学生语音作答。
2. 查看录音、转写文本、评分结果，并对学生进行追问。
3. 在课件中框选文本并调用词典、翻译、TTS 朗读和跟读评测。
4. 在教师工作区管理轻量资源并在课堂中调用。
5. 打开本阶段新增支持的 Office 课件格式并进行课堂批注。
6. 在教师工作区生成并导出 MP3 语音文件。
7. 在教师工作区查看按实际使用场景确认后的报表图表展示与报表预览。

## 3. 本阶段交付范围

1. 表达题课堂入口。
2. 录音作答接收与回放界面。
3. 转写查看与教师修正。
4. 表达题评分结果展示与排序。
5. 教师追问。
6. 点读、词典、翻译、TTS、跟读评测入口。
7. 资源中心轻量版。
8. 语音 MP3 生成页。
9. 本阶段新增课件格式支持： `PPTX`、`DOCX`、`XLSX`。
10. 报表中心图表展示版。

## 4. 用户角色与使用边界

| 角色   | 使用入口                 | 新增可用能力                             |
| ------ | ------------------------ | ---------------------------------------- |
| 教师   | 教师端客户端             | 表达题、语言工具、轻量资源中心、MP3 生成 |
| 学生   | 设备接入链路             | 语音作答、跟读评测                       |
| 管理员 | 不通过教师端执行治理动作 | 无                                       |

## 5. 业务流程

### 5.1 表达题流程

1. 教师进入课堂并打开表达题入口。
2. 教师输入题干、设置答题时间、设置是否允许追问。
3. 教师端通过本地设备接入能力开启语音接收状态。
4. 学生通过已接入且支持语音能力的设备录音作答。
5. 教师端将可被后端处理的录音文件或等效音频数据提交至后端。
6. 教师端收到转写与评分结果并展示。
7. 教师可修改转写文本、查看评分理由、按评分排序。
8. 教师可选择学生发起追问，形成新一轮表达记录。

### 5.2 点读与评测流程

1. 教师在课件预览区框选文本。
2. 工具面板显示：词典、翻译、朗读、跟读评测。
3. 教师点击词典查看结构化释义。
4. 教师点击翻译查看主译文和例句。
5. 教师点击朗读，获取并播放标准音频。
6. 教师点击跟读评测，学生录音后返回分数、星级和评语。

### 5.3 资源调用流程

1. 教师在教师工作区上传文件到资源中心。
2. 教师为资源设置资源名称、学科、标签。
3. 教师在课堂菜单中打开资源选择器。
4. 教师按格式或名称筛选并加载资源。

### 5.4 报表图表展示流程

1. 教师进入教师工作区的报表中心。
2. 教师按课次、日期、班级和报表类型筛选记录。
3. 教师查看报表明细预览。
4. 教师切换已确认纳入范围的图表展示。
5. 教师按同口径继续导出 `Excel` 报表文件。

## 6. 模块功能需求

### 6.1 表达题模块

| 项       | 说明                                                       |
| -------- | ---------------------------------------------------------- |
| 页面入口 | 课堂工作区 -> 互动工具栏 -> 表达题                         |
| 使用者   | 教师                                                       |
| 使用前提 | 当前课次进行中，已接入设备支持语音能力，学科能力开关已开启 |
| 核心操作 | 创建题目、开始录音、接收作答、查看转写、查看评分、追问     |
| 成功状态 | 有效录音、有效转写、有效评分结果展示在列表中               |
| 失败状态 | 录音失败、上传失败、转写失败、评分失败、设备不支持语音     |
| 数据保存 | 录音、转写、修正文本、评分结果、追问记录全部保存           |
| 导出     | 表达题结果通过报表中心导出                                 |
| 验收口径 | 教师可发题、查看录音与转写、得到评分结果、对指定学生追问   |

表达题创建时必须配置：

1. 题干。
2. 作答时长。
3. 允许追问开关。
4. 评分维度展示开关。

表达题设备语音链路边界如下：

1. 教师端需通过设备接入层完成语音作答能力调用。
2. 语音接收可采用团队选定的可维护实现，只要保证录音数据稳定采集。
3. 教师端需将可被后端处理的录音文件或等效音频数据提交到后端。
4. 转写和评分能力由后端或可配置的服务端能力完成，避免与教师端实现强绑定。

表达题结果列表必须显示：

1. 学生姓名。
2. 设备编号。
3. 录音时长。
4. 转写文本。
5. 修正文本。
6. 总评等级。
7. 总分。
8. 维度分。
9. 提交时间。

表达题界面操作必须支持：

1. 播放原始录音。
2. 编辑修正文本并保存。
3. 按总分排序。
4. 按提交时间排序。
5. 选择单个学生发起追问。

### 6.2 点读模块

| 项 | 说明 |
| --- | --- |
| 页面入口 | 课堂工作区 -> 课件区框选文本后弹出工具面板 |
| 使用者 | 教师 |
| 使用前提 | 当前打开资源为可选中文本内容的 PDF、DOCX、PPTX 或本地解析文本层资源 |
| 核心操作 | 框选文本、点击朗读、点击评测 |
| 成功状态 | 可获得选中文本并调用词典、翻译、朗读、跟读评测 |
| 失败状态 | 文本不可选、文本超长、服务失败 |
| 数据保存 | 点读查询记录与评测记录保存到后端 |
| 导出 | 通过报表中心导出评测记录 |
| 验收口径 | 教师对同一段文本可完成词典、翻译、朗读、跟读评测完整操作 |

文本框选规则固定如下：

1. 单次框选最大长度 `500` 字符。
2. 超长文本禁止调用服务并提示重新选择。
3. 无法解析文本层的资源不出现点读工具面板。

### 6.3 词典模块

词典结果展示固定字段如下：

1. 词条。
2. 发音或拼音。
3. 词性。
4. 释义。
5. 例句。
6. 学科术语说明。

课堂端词典面板必须支持：

1. 复制结果。
2. 固定面板。
3. 关闭面板。

### 6.4 翻译模块

翻译结果固定展示：

1. 原文。
2. 主译文。
3. 语言方向。
4. 例句，最多 `3` 条。

本阶段翻译范围固定为：

1. 中译英。
2. 英译中。

### 6.5 TTS 朗读模块

课堂端 TTS 参数固定支持：

1. 语言：中文、英语。
2. 音色：女声、男声。
3. 语速：慢速、标准、快速。

教师端必须支持对选中文本执行：

1. 在线播放。
2. 重新生成。

### 6.6 跟读评测模块

跟读评测结果列表必须显示：

1. 学生姓名。
2. 原文文本。
3. 录音时长。
4. 分数。
5. 星级。
6. 评语。
7. 提交时间。

课堂端必须支持：

1. 按学生查看结果。
2. 按分数排序。
3. 重播学生录音。

### 6.7 资源中心轻量版

| 项       | 说明                                     |
| -------- | ---------------------------------------- |
| 页面入口 | 教师工作区 -> 资源中心                   |
| 使用者   | 教师                                     |
| 使用前提 | 教师已登录且有资源访问权限               |
| 核心操作 | 上传、命名、分类、筛选、课堂调用         |
| 成功状态 | 资源上传成功并在课堂中可被打开           |
| 失败状态 | 文件过大、格式不支持、上传失败、名称重复 |
| 数据保存 | 资源元数据和文件地址保存到后端           |
| 导出     | 不涉及                                   |
| 验收口径 | 教师可从资源中心上传资源并在课堂中打开   |

资源中心支持的文件格式固定为：

1. `PNG`
2. `JPG`
3. `JPEG`
4. `BMP`
5. `PDF`
6. `MP4`
7. `PPTX`
8. `DOCX`
9. `XLSX`
10. `MP3`

资源元数据字段固定为：

1. 资源 ID。
2. 资源名称。
3. 文件格式。
4. 学科。
5. 标签。
6. 上传人。
7. 上传时间。
8. 文件大小。

### 6.8 语音 MP3 生成模块

| 项       | 说明                                           |
| -------- | ---------------------------------------------- |
| 页面入口 | 教师工作区 -> 语音 MP3                         |
| 使用者   | 教师                                           |
| 使用前提 | TTS 服务开关已开启                             |
| 核心操作 | 输入文本、选择音色、设置语速、生成、试听、导出 |
| 成功状态 | 成功生成 MP3 文件并可试听                      |
| 失败状态 | 文本为空、文本超长、TTS 服务失败、导出失败     |
| 数据保存 | 文本内容、生成参数、生成记录保存到后端         |
| 导出     | 单条导出 MP3                                   |
| 验收口径 | 教师可输入文本生成 MP3 并保存到本地            |

输入规则固定如下：

1. 支持直接输入文本。
2. 支持粘贴文本。
3. 支持导入 `TXT` 文件。
4. 单次文本长度上限受中台配置控制，默认不高于 `5000` 字符。

导出格式固定为：

1. `MP3`

### 6.9 Office 课件新增支持

本阶段课堂打开能力新增支持：

1. `PPTX`
2. `DOCX`
3. `XLSX`

支持方式固定为：

1. 由后端预处理生成预览页数据，教师端内置预览组件负责渲染。
2. 渲染后的页面允许叠加白板批注。
3. 允许页面翻页，不允许在课堂中编辑原文件内容。

### 6.10 报表中心图表展示模块

| 项 | 说明 |
| --- | --- |
| 页面入口 | 教师工作区 -> 报表中心 |
| 使用者 | 教师 |
| 使用前提 | `里程碑一` 已可导出固定口径报表文件，且双方已确认本阶段需落地的图表类型 |
| 核心操作 | 筛选记录、预览报表、切换图表、导出报表 |
| 成功状态 | 报表预览正确，图表展示正确，`Excel` 导出成功 |
| 失败状态 | 无记录、图表配置不支持、导出任务失败、下载失败、权限不足 |
| 数据保存 | 导出记录、筛选条件和图表查看记录保存到后端 |
| 导出 | 仅支持 `Excel` |
| 验收口径 | 教师可查看已确认图表类型对应的展示结果，并导出同口径 `Excel` 报表 |

本阶段图表范围固定规则如下：

1. 图表类型不在本清单预先固定为完整通用集合。
2. 仅实现双方在 `里程碑一` 上线后依据实际使用场景确认的图表类型。
3. 图表展示与报表导出必须使用同一数据口径。
4. 未经双方确认的图表样式、分析组件和高级交互不纳入本阶段交付。

本阶段报表类型固定为：

1. 作答情况报表。
2. 课次汇总报表。

筛选维度固定为：

1. 班级。
2. 课次日期。
3. 课次名称。
4. 报表类型。

## 7. 数据留存与查询要求

`里程碑二` 教师端新增留存的数据固定为：

1. 表达题题目配置。
2. 表达题录音上传记录。
3. 转写文本。
4. 教师修正文本。
5. 评分结果。
6. 追问记录。
7. 点读查询记录。
8. 翻译查询记录。
9. 跟读评测记录。
10. 资源上传记录。
11. MP3 生成记录。

## 8. 异常与失败处理

本阶段教师端必须显式处理：

1. 语音设备不支持。
2. 录音开始失败。
3. 录音上传失败。
4. 转写失败。
5. 评分失败。
6. 文本框选不可用。
7. 词典服务失败。
8. 翻译服务失败。
9. TTS 生成失败。
10. 跟读评测失败。
11. Office 文件解析失败。
12. 资源上传失败。

失败降级规则固定如下：

1. 转写失败时仍保留录音记录。
2. 评分失败时仍展示录音和转写结果。
3. TTS 失败时不得生成空白资源。
4. Office 解析失败时明确提示该文件无法用于课堂预览。

## 9. 非功能要求

1. 单条表达题录音上传后，`30` 秒内返回转写结果。
2. 跟读评测结果在提交后 `30` 秒内返回。
3. 资源上传进度必须可见。
4. Office 课件首次解析完成前界面必须显示加载状态。

## 10. 验收标准

1. 教师可发起表达题并看到学生录音作答结果。
2. 教师可播放录音、查看转写、保存修正文本、查看评分。
3. 教师可对指定学生发起追问。
4. 教师可对文本执行词典、翻译、朗读、跟读评测操作。
5. 教师可在资源中心上传并调用 `PPTX`、`DOCX`、`XLSX` 资源。
6. 教师可在语音 MP3 模块生成并导出 MP3。
7. 教师可在课堂中打开 `PPTX`、`DOCX`、`XLSX` 并叠加批注。

## 11. UI 交付说明

1. 对于有定制风格、特殊布局或关键交互要求的页面，需提供对应的 UI 线稿、原型或页面示意作为实现依据。
2. 当前未提供完整 UI 线稿或示意的页面，默认按行业通用规范、常规交互方式和项目既有风格进行设计与实现。
3. 颜色、字号、字重、间距等简单样式调整可在开发过程中配合修改。
4. 涉及页面结构、布局、信息层级或交互逻辑的调整，视为需求变更，需重新评估范围、排期与成本。

## 12. 依赖与前置条件

1. `里程碑一` 教师端和课堂主链路已上线。
2. 当前接入设备支持语音作答数据上传。
3. 后端已提供录音上传、转写、评分、词典、翻译、TTS、评测接口。
4. 中台已配置学科能力和语音服务参数。

## 13. 风险提示

1. 语音能力对教室噪声、麦克风质量、网络稳定性敏感。
2. Office 文件内容复杂时可能出现预览耗时较长或排版偏差。
3. 资源上传过多会增加教师筛选成本，需控制首期轻量范围。
