# 里程碑二 后端 PRD

## 1. 文档目的

本文档定义智能教学协同系统 `里程碑二` 阶段后端新增交付内容的正式范围、数据规则、异步处理逻辑与验收标准。本文档仅覆盖 `里程碑二` 合同内新增的语音、语言服务与资源能力。

## 2. 本阶段交付目标

`里程碑二` 后端需在已上线课堂主链路之上，交付以下新增能力：

1. 表达题录音上传、转写、评分、追问。
2. 点读相关的词典、翻译、TTS、跟读评测服务。
3. 轻量资源中心文件存储和元数据管理。
4. Office 文件预处理与预览数据服务。
5. 语音 MP3 生成与下载服务。
6. 语音与语言类服务的任务状态管理与失败降级。
7. 管理中台配置读写、指标查询与配置审计支撑。

## 3. 本阶段交付范围

### 3.1 必须交付

1. 表达题服务。
2. 录音文件服务。
3. ASR 转写服务。
4. 评分适配服务。
5. 词典服务。
6. 翻译服务。
7. TTS 服务。
8. 跟读评测服务。
9. 资源中心文件与元数据服务。
10. Office 预处理服务。
11. 语音与语言任务异步处理机制。
12. 配置中心支撑接口。
13. 语音与语言基础指标与配置审计支撑接口。

### 3.2 本阶段不包含范围

1. 试卷模板。
2. 测验实例。
3. AI 问答。
4. 课堂总结。
5. 导出任务中心。
6. 完整监控告警中心。

## 4. 用户角色与使用边界

| 角色   | 消费端   | 新增访问范围                         |
| ------ | -------- | ------------------------------------ |
| 教师   | 教师端   | 表达题、语言工具、资源中心、MP3 生成 |
| 学生   | 设备链路 | 录音作答、跟读录音提交               |
| 管理员 | 管理中台 | 语音与语言基础配置查询与修改         |

## 5. 业务流程

### 5.1 表达题处理流程

1. 教师端创建表达题任务。
2. 教师端本地接收主型号设备语音事件。
3. 教师端将录音文件上传到后端。
4. 后端生成表达题提交记录。
5. 后端异步触发 ASR。
6. ASR 成功后写入转写文本。
7. 后端异步触发评分服务。
8. 评分成功后返回等级、分数、维度分、评语。
9. 教师修正文本后，系统保留原始文本和修正文本。

### 5.2 点读与评测处理流程

1. 教师端提交选中文本和学科、语言。
2. 后端按请求类型调用词典、翻译或 TTS。
3. 学生提交跟读录音时，后端保存录音并触发评测任务。
4. 评测结果回传后，写入分数、星级和评语。

### 5.3 资源处理流程

1. 教师端上传资源文件。
2. 后端校验格式、大小、病毒扫描结果。
3. 后端写入对象存储并保存元数据。
4. 若为 Office 文件，则触发预处理任务并生成预览数据。
5. 教师端按资源 ID 打开课堂资源。

## 6. 模块功能需求

### 6.1 表达题服务

表达题任务字段固定为：

1. 表达题任务 ID。
2. 课次 ID。
3. 题干。
4. 作答时长。
5. 允许追问标记。
6. 状态。

表达题提交字段固定为：

1. 提交 ID。
2. 表达题任务 ID。
3. 学生 ID。
4. 设备编号。
5. 录音文件 ID。
6. 录音时长。
7. 原始转写文本。
8. 教师修正文本。
9. 总分。
10. 等级。
11. 维度分。
12. 评语。
13. 提交时间。
14. 追问轮次。

业务规则固定如下：

1. 录音上传成功后才创建有效提交。
2. 转写失败时提交状态为“转写失败”，不得删除录音。
3. 评分失败时提交状态为“评分失败”，不得删除录音和文本。
4. 同一轮表达题每名学生允许重新提交 `1` 次，最终以最后一次有效提交为准。

表达题音频接收边界固定如下：

1. 后端只接收教师端上传的标准 `WAV` 文件。
2. 后端不直接接收 Windows SDK 原始回调流。
3. 后端不直接运行本地设备驱动或 DLL。

### 6.2 录音文件服务

录音文件服务必须支持：

1. 接收教师端上传的 `WAV` 文件。
2. 记录文件大小、时长、采样率、来源设备。
3. 返回受控访问地址。

录音文件校验固定为：

1. 格式仅接受 `WAV`。
2. 单文件大小上限 `20MB`。
3. 单文件时长上限 `300` 秒。

### 6.3 ASR 转写服务

ASR 服务输入固定为：

1. 录音文件地址。
2. 语言类型：中文、英语。
3. 学科。

ASR 服务输出固定为：

1. 原始文本。
2. 识别语言。
3. 置信度。
4. 处理状态。

### 6.4 评分适配服务

评分适配服务必须返回：

1. 总分。
2. 总评等级。
3. 维度分。
4. 维度名称。
5. 评语。
6. 改进建议。

`里程碑二` 固定评分维度为：

1. 发音准确性。
2. 流畅度。
3. 内容完整性。

### 6.5 词典服务

词典服务固定支持：

1. 中文词条。
2. 英文词条。
3. 学科术语说明。

输出字段固定为：

1. 词条。
2. 发音或拼音。
3. 词性。
4. 释义。
5. 例句。
6. 学科说明。

### 6.6 翻译服务

翻译服务固定支持：

1. 中译英。
2. 英译中。

输出字段固定为：

1. 原文。
2. 主译文。
3. 例句列表。
4. 语言方向。

### 6.7 TTS 服务

TTS 服务输入固定为：

1. 文本内容。
2. 语言。
3. 音色。
4. 语速。

TTS 服务输出固定为：

1. 音频文件 ID。
2. 文件格式： `MP3`
3. 文件大小。
4. 时长。

缓存规则固定如下：

1. 相同文本。
2. 相同语言。
3. 相同音色。
4. 相同语速。

满足以上四项时复用历史音频。

### 6.8 跟读评测服务

跟读评测字段固定为：

1. 评测记录 ID。
2. 课次 ID。
3. 学生 ID。
4. 原文文本。
5. 标准语言。
6. 录音文件 ID。
7. 分数。
8. 星级。
9. 评语。
10. 提交时间。

### 6.9 资源中心服务

资源服务支持的文件格式固定为：

1. `PNG`
2. `JPG`
3. `JPEG`
4. `BMP`
5. `PDF`
6. `MP4`
7. `PPTX`
8. `DOCX`
9. `XLSX`
10. `MP3`

资源元数据字段固定为：

1. 资源 ID。
2. 文件名。
3. 资源名称。
4. 格式。
5. 学科。
6. 标签。
7. 文件大小。
8. 上传教师 ID。
9. 上传时间。
10. 预处理状态。

### 6.10 Office 预处理服务

预处理服务职责固定为：

1. 接收 `PPTX`、`DOCX`、`XLSX` 文件。
2. 生成教师端可加载的预览页数据。
3. 记录每页页码、宽高、缩略图地址。

预处理失败时固定返回：

1. 不支持内容。
2. 文件损坏。
3. 解析超时。

预处理输出必须至少包含：

1. 预览页总页数。
2. 每页缩略图地址。
3. 每页主预览地址。
4. 每页宽高。

### 6.11 异步任务机制

本阶段异步任务对象固定为：

1. ASR 转写。
2. 评分。
3. TTS 生成。
4. Office 预处理。

任务状态固定为：

1. 待处理。
2. 处理中。
3. 成功。
4. 失败。

失败任务必须保留：

1. 任务类型。
2. 请求来源。
3. 错误码。
4. 错误信息。
5. 失败时间。

### 6.12 配置与指标支撑服务

本阶段后端必须向管理中台提供以下支撑能力：

1. 读取与写入语音服务配置、学科能力配置、评分规则配置、任务限制参数。
2. 配置变更仅对新发起请求生效，不影响处理中任务。
3. 配置变更必须记录操作人、配置项、变更前值、变更后值、结果、时间。
4. 提供 ASR、TTS、评分、Office 预处理成功率与日调用次数查询。
5. 指标查询结果必须支持按时间窗口聚合。

## 7. 数据留存与查询要求

`里程碑二` 后端新增留存以下数据：

1. 表达题任务。
2. 表达题提交。
3. 原始录音文件。
4. 转写文本。
5. 修正文本。
6. 评分结果。
7. 跟读评测结果。
8. 点读查询记录。
9. 翻译查询记录。
10. TTS 生成记录。
11. 资源元数据。
12. Office 预处理结果。
13. 服务配置快照。
14. 配置变更审计记录。
15. 语音与语言类基础指标汇总。

## 8. 异常与失败处理

必须显式处理以下失败场景：

1. 录音文件校验失败。
2. 文件上传失败。
3. ASR 服务失败。
4. 评分服务失败。
5. 词典服务失败。
6. 翻译服务失败。
7. TTS 服务失败。
8. 跟读评测失败。
9. Office 预处理失败。
10. 资源病毒扫描失败。

失败降级规则固定如下：

1. ASR 失败时保留录音并允许人工回看。
2. 评分失败时保留录音和转写文本。
3. TTS 失败时不生成空文件。
4. Office 预处理失败时资源状态标记为“不可预览”，但保留上传记录。

## 9. 非功能要求

1. 表达题转写结果应在 `30` 秒内返回。
2. 跟读评测结果应在 `30` 秒内返回。
3. 资源上传时必须支持断点失败重传策略说明，至少保证失败后可重新上传。
4. TTS 缓存命中时响应应小于 `3` 秒。

## 10. 验收标准

1. 后端可接收表达题录音并完成保存。
2. 后端可返回表达题转写和评分结果。
3. 后端可保存教师修正文本和追问记录。
4. 后端可提供词典、翻译、TTS、跟读评测服务。
5. 后端可保存资源文件和 Office 预处理结果。
6. 教师端可基于后端返回结果打开资源、回看语音和语言类数据。
7. 管理中台可通过后端完成语音与语言配置读写、指标查看与配置审计查询。

## 11. 依赖与前置条件

1. `里程碑一` 后端已上线。
2. 教师端本地可转发语音相关设备事件。
3. 已选定可用的 ASR、TTS、评分供应商并完成适配。
4. 云端存储与异步任务基础设施已可用。

## 12. 风险提示

1. 语音服务供应商稳定性直接影响教师端体验。
2. Office 预处理受文件复杂度影响较大。
3. 大量音频文件会快速增加存储成本。
