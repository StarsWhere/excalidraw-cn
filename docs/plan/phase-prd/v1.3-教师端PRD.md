# v1.3 教师端 PRD

## 1. 文档目的

本文档定义智能教学协同系统 `v1.3` 阶段教师端新增交付内容的正式范围、业务规则、验收标准与依赖边界。本文档仅覆盖 `v1.3` 合同范围内新增的测验、AI 问答与课堂总结能力。

## 2. 本阶段交付目标

`v1.3` 教师端需交付以下新增业务闭环：

1. 教师导入试卷模板并发起正式测验。
2. 学生完成测验作答，教师查看进度与结果。
3. 教师查看个人报告和班级报告。
4. 教师在课堂中接收学生问题并触发 AI 回答。
5. 教师在课后查看课堂总结并导出结果文件。

## 3. 本阶段交付范围

### 3.1 必须交付

1. 试卷模板导入入口。
2. 测验发起页。
3. 测验执行页。
4. 测验结果回看页。
5. 个人报告查看页。
6. 班级报告查看页。
7. AI 问答页。
8. 课堂总结页。
9. 测验报告与课堂总结导出入口。

### 3.2 本阶段不包含范围

1. 学生独立 App。
2. 自定义题型脚本。
3. 开放式 AI 助手聊天窗口。
4. 跨学校数据汇总。

## 4. 用户角色与使用边界

| 角色 | 使用入口 | 新增可用能力 |
| --- | --- | --- |
| 教师 | 教师端客户端 | 试卷导入、发起测验、回看报告、AI 问答、查看课堂总结 |
| 学生 | 设备链路 | 测验作答、问题提交 |
| 管理员 | 不通过教师端发起课堂业务 | 无 |

## 5. 业务流程

### 5.1 测验流程

1. 教师在教师工作区导入试卷模板。
2. 教师在课堂中选择试卷并发起测验。
3. 系统向学生设备下发测验题目与答题时间。
4. 学生提交客观题答案和语音题答案。
5. 教师实时查看进度、剩余时间、已交卷人数。
6. 测验结束后查看个人报告和班级报告。

### 5.2 AI 问答流程

1. 教师在课堂中打开 AI 问答面板。
2. 学生提交语音或文本问题。
3. 系统将问题列表返回教师端。
4. 教师选择单个问题点击“AI 回答”。
5. 系统返回答案并展示在教师端。
6. 课后生成课堂总结供教师查看和导出。

## 6. 模块功能需求

### 6.1 试卷模板导入模块

| 项       | 说明                                       |
| -------- | ------------------------------------------ |
| 页面入口 | 教师工作区 -> 测验中心                     |
| 使用者   | 教师                                       |
| 使用前提 | 教师具有测验权限                           |
| 核心操作 | 上传模板、校验、查看试卷列表               |
| 成功状态 | 试卷进入可发起状态                         |
| 失败状态 | 模板字段缺失、题型非法、分值异常、文件损坏 |
| 数据保存 | 试卷模板与校验结果保存到后端               |
| 导出     | 不涉及                                     |
| 验收口径 | 教师可上传合法模板并在列表中看到试卷       |

模板导入文件固定支持：

1. `Excel`

模板字段固定为：

1. 题号。
2. 题型。
3. 题干。
4. 选项。
5. 标准答案。
6. 分值。
7. 作答时长。
8. 难度。
9. 知识点。

支持题型固定为：

1. 判断题。
2. 单选题。
3. 多选题。
4. 语音题。
5. 口头简答题。

### 6.2 测验发起模块

| 项       | 说明                                         |
| -------- | -------------------------------------------- |
| 页面入口 | 课堂工作区 -> 测验                           |
| 使用者   | 教师                                         |
| 使用前提 | 当前课次进行中，已存在可用试卷               |
| 核心操作 | 选择试卷、设置随机项、设置交卷规则、开始测验 |
| 成功状态 | 测验进入进行中状态                           |
| 失败状态 | 试卷不存在、测验状态冲突、设备未就绪         |
| 数据保存 | 测验实例保存至后端                           |
| 导出     | 不涉及                                       |
| 验收口径 | 教师可发起一次正式测验并看到学生作答进度     |

测验发起页必须允许配置：

1. 试卷。
2. 开始时间。
3. 结束时间。
4. 是否超时自动交卷。
5. 是否随机题序。
6. 是否随机选项顺序。

### 6.3 测验执行页

测验执行页必须显示：

1. 当前试卷名称。
2. 剩余时间。
3. 已交卷人数。
4. 未交卷人数。
5. 当前进行状态：待开始、进行中、已截止、已完成。
6. 结束测验按钮。

教师端必须支持以下动作：

1. 手动截止测验。
2. 查看单题统计。
3. 查看学生提交状态。

### 6.4 测验结果回看页

结果回看页固定分为两个视图：

1. 个人报告视图。
2. 班级报告视图。

个人报告必须显示：

1. 学生姓名。
2. 试卷名称。
3. 总分。
4. 单题得分。
5. 语音题评分结果。
6. 提交时间。
7. 改进建议。

班级报告必须显示：

1. 平均分。
2. 最高分。
3. 最低分。
4. 分数分布。
5. 共性错误题。
6. 班级完成率。

测验报告导出格式固定为：

1. `Excel`

### 6.5 AI 问答模块

| 项       | 说明                                           |
| -------- | ---------------------------------------------- |
| 页面入口 | 课堂工作区 -> AI 问答                          |
| 使用者   | 教师                                           |
| 使用前提 | AI 问答开关已开启                              |
| 核心操作 | 查看问题列表、筛选问题、选择问题、触发 AI 回答 |
| 成功状态 | 成功展示结构化问题和 AI 回答                   |
| 失败状态 | 问题识别失败、AI 生成失败、内容过滤拦截        |
| 数据保存 | 问题、答案、教师选择记录保存到后端             |
| 导出     | 通过课堂总结导出                               |
| 验收口径 | 教师可选择问题并看到 AI 回答结果               |

AI 问答页必须显示：

1. 提问学生。
2. 问题内容。
3. 问题来源：语音、文本。
4. 问题时间。
5. 问题状态：待处理、已选中、已回答、已忽略。
6. AI 回答内容。

### 6.6 课堂总结页

课堂总结页必须展示：

1. 本课互动次数。
2. 本课测验次数。
3. 本课问题数。
4. 问题摘要。
5. 教学建议。
6. 关键学生表现摘要。

课堂总结导出固定支持：

1. `TXT`
2. `PDF`

## 7. 数据留存与查询要求

`v1.3` 教师端新增留存数据固定为：

1. 试卷导入记录。
2. 测验实例。
3. 单题作答结果。
4. 个人报告。
5. 班级报告。
6. AI 问题列表。
7. AI 回答结果。
8. 课堂总结查看与导出记录。

## 8. 异常与失败处理

本阶段教师端必须显式处理：

1. 试卷模板校验失败。
2. 测验创建失败。
3. 测验过程中设备掉线。
4. 自动交卷失败。
5. 报告查询失败。
6. 问题识别失败。
7. AI 回答失败。
8. 内容过滤命中。
9. 课堂总结生成失败。
10. 导出失败。

失败处理规则固定如下：

1. 题目模板校验失败时不得入库为可发布试卷。
2. AI 回答失败时保留原问题记录。
3. 课堂总结失败时允许重新生成。

## 9. 非功能要求

1. 测验进度刷新周期不超过 `3` 秒。
2. AI 回答应在 `60` 秒内返回。
3. 课堂总结应在课次结束后 `5` 分钟内生成。
4. 报告页在 `10,000` 条记录内可正常分页浏览。

## 10. 验收标准

1. 教师可导入合法试卷模板并发起测验。
2. 学生可在测验中提交答案，教师可查看进度。
3. 教师可查看个人报告与班级报告。
4. 教师可在课堂中查看问题列表并触发 AI 回答。
5. 教师可查看课堂总结并导出。

## 11. 依赖与前置条件

1. `v1.1` 和 `v1.2` 能力已上线。
2. 后端已提供测验、AI 问答、课堂总结和导出任务接口。
3. 中台已配置测验权限、AI 问答权限和相关参数。

## 12. 风险提示

1. 测验模板质量会直接影响测验执行稳定性。
2. AI 回答存在内容合规风险，教师仍需选择与确认。
3. 大班级测验会提高报告生成耗时。
