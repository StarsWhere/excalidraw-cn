# v1.1 教师端 PRD

## 1. 文档目的

本文档定义智能教学协同系统 `v1.1` 阶段教师端的正式交付范围、业务规则、验收口径与依赖边界。本文档仅描述 `v1.1` 合同范围内教师端需要交付并可上线使用的能力，不描述其他阶段内容。

## 2. 本阶段交付目标

`v1.1` 教师端需交付一个可独立商用验收的 Windows 桌面客户端，教师在本阶段能够完成以下完整业务闭环：

1. 使用教师账号登录客户端并进入教师工作区。
2. 在教师工作区完成班级查看、学生导入、设备状态检查、报表回看。
3. 选择班级与教室进入课堂。
4. 在课堂中打开本阶段支持的课件文件并进行批注。
5. 发起判断题、单选题、多选题和抢答式选择题互动。
6. 查看实时统计结果。
7. 在课后回看记录并导出固定口径 Excel 报表。

## 3. 本阶段交付范围

### 3.1 必须交付

1. 登录页与自动登录。
2. 教师端双工作区框架：教师管理工作区、课堂工作区。
3. 教师管理工作区：班级管理、学生导入、设备管理、报表中心、进入课堂入口、最小个人设置。
4. 课堂工作区：菜单栏、白板区域、互动工具栏、页面工具栏。
5. 课堂基础工具：书写、橡皮、文本、计时器。
6. 选择题互动：判断题、单选题、多选题、抢答模式。
7. 本阶段课件打开能力： `PNG`、`JPG`、`JPEG`、`BMP`、`PDF`。
8. 设备联动能力：设备连接状态显示、设备在线刷新、学生绑定状态确认、按键作答接收。
9. 报表回看与导出：作答情况报表、课次汇总报表，导出格式固定为 `Excel`。

### 3.2 本阶段不包含范围

1. 表达题、录音作答、语音回放。
2. 点读、词典、翻译、TTS、跟读评测。
3. 试卷模板、正式测验、自动评分。
4. AI 问答、课堂总结。
5. 复杂资源中心。
6. `PPT`、`PPTX`、`DOC`、`DOCX`、`XLS`、`XLSX`、`QVF` 打开能力。
7. 多校区、多组织切换。
8. 教师端内置运维监控页面。

## 4. 用户角色与使用边界

| 角色 | 使用入口 | 可用能力 | 不可用能力 |
| --- | --- | --- | --- |
| 教师 | 教师端客户端 | 登录、班级查看、学生导入、设备检查、进入课堂、发起互动、回看报表 | 用户授权、系统配置、审计查询 |
| 管理员 | 不通过教师端执行管理动作 | 无 | 不在教师端进行账号授权与系统治理 |
| 学生 | 不直接使用教师端 | 无 | 不进入教师端界面 |

教师端只承担教师课前准备、授课、课后回看的桌面端职责，不承担管理员治理职责，不承载云端监控与审计查询界面。

## 5. 业务流程

### 5.1 登录到进入课堂流程

1. 教师输入账号密码登录。
2. 客户端请求后端认证服务并获取访问令牌、用户信息、学科权限、可见班级列表。
3. 客户端进入教师管理工作区。
4. 教师在班级管理中确认授课班级，在设备管理中确认设备在线状态。
5. 教师点击“进入课堂”，选择班级、教室和学科。
6. 客户端向后端申请创建课次。
7. 课次创建成功后，客户端切换至课堂工作区。

### 5.2 课堂互动流程

1. 教师在课堂工作区打开课件或空白页。
2. 教师使用书写、橡皮、文本工具进行批注。
3. 教师在互动工具栏创建题目并设置题型、答案、答题模式、截止时间。
4. 客户端调用本地 SDK 控制接收器开始题目，并同步通知后端创建互动任务。
5. 学生通过已绑定答题器提交答案。
6. 客户端接收本地 SDK 回传的按键事件并实时推送给后端。
7. 后端返回统计结果，客户端实时刷新图表与列表。
8. 教师结束题目，客户端关闭题目状态并保存互动记录。

### 5.3 课后回看流程

1. 教师返回教师管理工作区。
2. 教师进入报表中心，按课次、日期、班级筛选记录。
3. 教师预览作答情况报表或课次汇总报表。
4. 教师点击导出，生成并下载 Excel 文件。

## 6. 模块功能需求

### 6.1 登录模块

| 项       | 说明                                                             |
| -------- | ---------------------------------------------------------------- |
| 页面入口 | 客户端启动首页                                                   |
| 使用者   | 教师                                                             |
| 使用前提 | 已由管理中台分配教师账号且账号状态正常                           |
| 核心操作 | 输入账号、密码，勾选记住密码或自动登录，点击登录                 |
| 成功状态 | 登录成功后进入教师管理工作区，显示教师姓名、学科权限、可见班级   |
| 失败状态 | 账号不存在、密码错误、账号锁定、网络异常、权限不足               |
| 数据保存 | 本地保存登录偏好；令牌按安全策略存储                             |
| 导出     | 不涉及                                                           |
| 验收口径 | 正确账号可登录，错误账号有明确提示，自动登录可在令牌有效期内生效 |

登录页必须包含以下元素：

1. 账号输入框。
2. 密码输入框。
3. 记住密码复选项。
4. 自动登录复选项。
5. 登录按钮。
6. 登录失败提示区域。

### 6.2 教师管理工作区框架

教师管理工作区采用固定三段结构：

1. 顶部栏：显示工作区名称、教师姓名、学科、退出登录、进入课堂入口。
2. 左侧导航：班级管理、设备管理、报表中心、个人设置。
3. 右侧内容区：展示对应模块页面内容。

教师在未进入课堂前允许自由切换模块；进入课堂后默认切换到课堂工作区。

### 6.3 班级管理模块

| 项       | 说明                                                     |
| -------- | -------------------------------------------------------- |
| 页面入口 | 教师管理工作区 -> 班级管理                               |
| 使用者   | 教师                                                     |
| 使用前提 | 教师已登录且具备班级查看权限                             |
| 核心操作 | 查看班级列表、查看班级学生、批量导入学生、按班级进入课堂 |
| 成功状态 | 班级列表正确展示，导入成功学生进入班级名单               |
| 失败状态 | 导入模板错误、字段缺失、重复学号、班级不存在             |
| 数据保存 | 导入成功与失败记录保存至后端                             |
| 导出     | 本阶段不支持从教师端导出班级数据                         |
| 验收口径 | 教师可完成学生 Excel 导入并查看失败原因                  |

班级管理页面必须包含：

1. 班级列表区：显示班级名称、年级、学科、学生人数。
2. 学生明细区：显示学生姓名、学号、绑定设备号、状态。
3. 导入操作区：上传 `Excel` 学生名单文件。
4. 进入课堂按钮。

学生导入规则固定如下：

1. 仅支持 `Excel` 模板导入。
2. 必填字段：学生姓名、学号、所属班级。
3. 可选字段：性别、座号、设备编号。
4. 同一班级内学号不得重复。
5. 导入失败时必须返回逐行失败原因。

### 6.4 设备管理模块

| 项       | 说明                                                         |
| -------- | ------------------------------------------------------------ |
| 页面入口 | 教师管理工作区 -> 设备管理                                   |
| 使用者   | 教师                                                         |
| 使用前提 | 本地已安装设备 SDK，接收器已连接，教师具备对应班级可见权限   |
| 核心操作 | 查看在线状态、刷新状态、确认学生绑定、解绑、休眠             |
| 成功状态 | 设备状态与后端记录一致，教师可确认进入课堂条件               |
| 失败状态 | SDK 未初始化、接收器未连接、设备断开、状态同步失败           |
| 数据保存 | 设备在线状态、刷新时间、绑定关系保存至后端                   |
| 导出     | 不涉及                                                       |
| 验收口径 | 教师可在进入课堂前看到设备在线列表，并能执行刷新、解绑、休眠 |

设备管理页面必须显示：

1. 设备编号。
2. 学生姓名。
3. 在线状态：在线、离线、未绑定、异常。
4. 电量状态。
5. 信号状态。
6. 最近心跳时间。
7. 操作按钮：刷新、解绑、休眠。

本阶段设备交互边界固定如下：

1. 教师端本地集成 `docs/plan/SDK` 提供的 Node Native 模块与 DLL。
2. 教师端本地必须封装并调用 SDK 示例中可用的设备控制动作：
   `StartSession`、`EndSession`、`StartQuestion`、`EndQuestion`、`SetContext`、`AutomaticTest(Sleep)`。
3. 进入课堂时必须先成功执行设备会话初始化，再允许发起题目。
4. 休眠动作必须映射到 SDK 的设备休眠能力，不允许只在界面层提示。
5. 云端后端不直接加载 Windows SDK。
6. 教师端负责从本地 SDK 获取连接事件、按键事件、设备状态事件。
7. 教师端负责将本地事件同步到后端。

### 6.5 报表中心模块

| 项       | 说明                                                   |
| -------- | ------------------------------------------------------ |
| 页面入口 | 教师管理工作区 -> 报表中心                             |
| 使用者   | 教师                                                   |
| 使用前提 | 已存在课次记录或互动记录                               |
| 核心操作 | 筛选记录、预览报表、导出报表                           |
| 成功状态 | 预览数据正确，Excel 导出成功                           |
| 失败状态 | 无记录、导出任务失败、下载失败、权限不足               |
| 数据保存 | 导出记录和筛选条件保存到后端审计记录                   |
| 导出     | 仅支持 Excel                                           |
| 验收口径 | 可导出作答情况报表与课次汇总报表，字段完整且中文不乱码 |

筛选维度固定为：

1. 班级。
2. 课次日期。
3. 课次名称。
4. 报表类型。

本阶段报表类型固定为：

1. 作答情况报表。
2. 课次汇总报表。

作答情况报表字段固定为：

1. 课次 ID。
2. 题目 ID。
3. 题型。
4. 题干摘要。
5. 正确答案。
6. 应到人数。
7. 实答人数。
8. 参与率。
9. 正确人数。
10. 正确率（按应到）。
11. 正确率（按实答）。
12. 未作答人数。
13. 缺席人数。
14. 选项分布。
15. 开始时间。
16. 结束时间。
17. 用时。

课次汇总报表字段固定为：

1. 课次 ID。
2. 班级名称。
3. 教师姓名。
4. 互动次数。
5. 应到人数。
6. 实答人数。
7. 参与率。
8. 平均正确率（按应到）。
9. 平均正确率（按实答）。
10. 导出时间。

导出命名固定为：

`{班级名称}_{课次日期}_{报表类型}.xlsx`

### 6.6 课堂工作区框架

课堂工作区固定为四区结构：

1. 菜单栏。
2. 白板与课件展示区。
3. 互动工具栏。
4. 页面工具栏。

课堂进行中教师端必须满足以下界面规则：

1. 当前课次名称常驻可见。
2. 当前班级名称常驻可见。
3. 结束课堂按钮常驻可见。
4. 当前题目状态常驻可见。
5. 设备连接异常提示可见。

### 6.7 菜单栏模块

本阶段菜单栏仅包含以下动作：

1. 打开文件。
2. 保存课堂草稿。
3. 返回教师工作区。
4. 结束课堂。

打开文件只支持以下格式：

1. `PNG`
2. `JPG`
3. `JPEG`
4. `BMP`
5. `PDF`

打开失败提示必须区分：

1. 文件不存在。
2. 文件损坏。
3. 格式不支持。
4. 文件被占用。
5. 权限不足。

### 6.8 白板区域

白板区域承担课件展示与批注叠加能力。

本阶段必须支持：

1. 在空白页书写。
2. 在图片上书写。
3. 在 PDF 页上书写。
4. 在视频播放画面上叠加批注。
5. 多页浏览与新增空白页。

批注数据保存规则：

1. 批注与当前课次绑定。
2. 批注按页面保存。
3. 课堂异常退出后，重新进入同一课次可恢复草稿状态。

### 6.9 互动工具栏

本阶段互动工具栏仅包含以下工具：

1. 书写。
2. 橡皮。
3. 文本。
4. 计时器。
5. 选择题互动。

#### 6.9.1 书写

1. 支持颜色选择：黑、红、蓝、绿。
2. 支持线宽选择：细、中、粗。
3. 支持撤销、重做。

#### 6.9.2 橡皮

1. 支持擦除当前页批注。
2. 支持清空当前页批注。

#### 6.9.3 文本

1. 支持插入文本框。
2. 支持修改字号： 16、24、32。
3. 支持修改颜色：黑、红、蓝。

#### 6.9.4 计时器

1. 支持 `1`、`3`、`5`、`10` 分钟快捷倒计时。
2. 支持暂停、继续、重置。
3. 倒计时结束时本地弹出提示，不向设备发送语音或震动控制。

#### 6.9.5 选择题互动

本阶段正式支持的题型与模式如下：

| 题型   | 模式                         |
| ------ | ---------------------------- |
| 判断题 | 全班作答、抢答               |
| 单选题 | 全班作答、抢答、指定学生作答 |
| 多选题 | 全班作答                     |

创建题目时必须配置：

1. 题型。
2. 题干。
3. 选项。
4. 正确答案。
5. 作答模式。
6. 截止时间。
7. 是否允许修改答案。

课堂端必须显示以下实时信息：

1. 已作答人数。
2. 未作答人数。
3. 缺席人数。
4. 每个选项人数和比例。
5. 抢答成功名单和顺序。

### 6.10 页面工具栏

本阶段页面工具栏固定为：

1. 新增空白页。
2. 上一页。
3. 当前页码展示。
4. 下一页。
5. 页面缩略预览。

页面删除能力本阶段不开放。

## 7. 数据留存与查询要求

教师端必须向后端提交并可回查以下数据：

1. 登录成功与失败结果。
2. 班级进入课堂记录。
3. 课次开始与结束时间。
4. 设备在线状态快照。
5. 每道题的题目配置。
6. 每个学生的提交答案。
7. 每次导出行为。
8. 每页批注草稿。

教师端本地需保存：

1. 登录偏好。
2. 当前窗口状态。
3. 当前课次未提交草稿。
4. 最近一次打开文件路径。

## 8. 异常与失败处理

本阶段教师端必须显式处理以下异常：

1. 登录失败：明确提示账号不存在、密码错误、账号锁定、网络异常。
2. 权限不足：提示“当前账号无权访问该班级或该模块”。
3. SDK 初始化失败：提示设备功能不可用，禁止进入需要设备联动的课堂互动。
4. 设备未连接：设备管理页明确显示“未连接”，进入课堂时弹出确认。
5. 设备状态异常：允许刷新，不允许隐藏异常。
6. 题目创建失败：不创建本地假成功状态。
7. 实时统计超时：显示“统计更新中”，不得清空已返回数据。
8. 导出失败：显示失败原因并允许重新发起。
9. 文件损坏或格式不支持：阻止打开并保留当前课堂状态。
10. 课堂中断：下次重新进入同一课次时恢复到上次未结束状态。

## 9. 非功能要求

1. 教师端运行环境固定为 Windows。
4. 客户端异常退出后，同一课次草稿可恢复。
5. 所有导出文件名必须符合统一命名规则。
6. 中文界面不得出现乱码。

## 10. 验收标准

1. 教师可使用分配账号登录并进入教师管理工作区。
2. 教师可导入学生 Excel 并查看失败原因。
3. 教师可在设备管理页看到在线设备、绑定状态、电量和信号。
4. 教师可创建课次并进入课堂。
5. 教师可打开 `PNG`、`JPG`、`JPEG`、`BMP`、`PDF` 文件。
6. 教师可使用书写、橡皮、文本、计时器工具。
7. 教师可发起判断题、单选题、多选题和抢答互动。
8. 学生通过答题器提交答案后，教师端统计结果实时更新。
9. 教师可在报表中心预览并导出作答情况报表和课次汇总报表。
10. 课堂异常退出后再次进入，可恢复未结束课次。

## 11. 依赖与前置条件

1. 管理中台已完成教师账号、班级、学生、教室基础数据初始化。
2. 后端已提供认证、课次、设备、互动、报表接口。
3. 教师端运行设备已安装 `docs/plan/SDK` 对应主型号接收器依赖。
4. 教师端能够访问云端后端服务。

## 12. 风险提示
