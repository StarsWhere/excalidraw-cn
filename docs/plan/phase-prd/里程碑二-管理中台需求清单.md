# 里程碑二 管理中台 需求清单

## 1. 文档目的

本文档定义智能教学协同系统 `里程碑二` 阶段管理中台新增治理能力的正式范围、配置规则与验收标准。

运行环境：新版 Chrome 浏览器中的 Web 管理中台。

## 2. 本阶段交付目标

`里程碑二` 管理中台需新增以下治理能力：

1. 管理语音与语言类服务开关。
2. 管理学科能力差异配置。
3. 管理评分维度与权重。
4. 管理资源上传限制和任务参数。
5. 查看语音与语言类任务基础指标。

## 3. 本阶段交付范围

1. 语音服务配置页。
2. 学科能力配置页。
3. 评分规则配置页。
4. 任务限制参数配置页。
5. 语音与语言服务基础指标页。
6. 配置变更审计记录。

## 4. 用户角色与使用边界

| 角色   | 使用入口                 | 新增可用能力                     |
| ------ | ------------------------ | -------------------------------- |
| 管理员 | 管理中台 Web             | 配置语音与语言服务、查看基础指标 |
| 教师   | 不在管理中台配置服务参数 | 无                               |

## 5. 业务流程

### 5.1 学科能力配置流程

1. 管理员进入学科能力配置页。
2. 选择学科。
3. 开启或关闭表达题、点读、词典、翻译、TTS、跟读评测。
4. 保存配置。
5. 系统记录审计日志。

### 5.2 评分规则配置流程

1. 管理员进入评分规则配置页。
2. 选择学科和语言类型。
3. 配置维度名称和权重。
4. 保存配置。
5. 配置从新请求开始生效。

## 6. 模块功能需求

### 6.1 语音服务配置页

语音服务配置页必须支持配置：

1. ASR 服务启用状态。
2. TTS 服务启用状态。
3. 评分服务启用状态。
4. 默认语言。
5. 最大并发任务数。

供应商配置字段固定为：

1. 服务类型。
2. 服务名称。
3. 认证参数。
4. 状态：启用、停用。

### 6.2 学科能力配置页

每个学科必须可独立配置以下开关：

1. 表达题。
2. 点读。
3. 词典。
4. 翻译。
5. TTS。
6. 跟读评测。
7. 资源中心。
8. Office 预览。

### 6.3 评分规则配置页

本阶段评分规则配置页必须支持：

1. 配置维度名称。
2. 配置权重。
3. 配置评分总分。

`里程碑二` 支持配置的维度固定为：

1. 发音准确性。
2. 流畅度。
3. 内容完整性。

权重规则固定为：

1. 权重总和必须等于 `100`。
2. 单维度权重必须为整数。

### 6.4 任务限制参数页

本阶段必须支持配置：

1. 单条录音最大时长。
2. 单文件最大大小。
3. TTS 单次最大文本长度。
4. 文本框选最大字符数。
5. 资源上传大小上限。

### 6.5 基础指标页

基础指标页展示以下内容：

1. ASR 调用成功率。
2. TTS 调用成功率。
3. 评分调用成功率。
4. Office 预处理成功率。
5. 日调用次数。

### 6.6 配置变更审计

必须记录以下变更：

1. 服务启停。
2. 供应商参数修改。
3. 学科能力开关修改。
4. 评分权重修改。
5. 限制参数修改。

审计字段固定为：

1. 操作人。
2. 操作时间。
3. 配置项。
4. 变更前值。
5. 变更后值。
6. 结果。

## 7. 数据留存与查询要求

`里程碑二` 管理中台新增留存：

1. 供应商配置。
2. 学科能力配置。
3. 评分规则配置。
4. 任务限制参数。
5. 相关审计记录。

## 8. 异常与失败处理

必须显式处理：

1. 权重和不为 `100`。
2. 配置项缺失。
3. 服务启用但认证参数不完整。
4. 保存失败。
5. 指标查询失败。

## 9. 非功能要求

1. 配置页面操作必须形成审计记录。
2. 高风险配置变更必须二次确认：服务停用、权重修改、限制阈值下调。
3. 指标页面刷新周期不超过 `5` 分钟。
4. CSV 导出文件编码固定为 GBK，其他导出内容中的文本字段统一按 UTF-8 编码规范处理。
5. 若设备或操作系统版本过旧，或系统字符集配置异常，不保证所有环境中的展示结果均可完全避免乱码。

## 10. 验收标准

1. 管理员可为不同学科配置表达题、点读、词典、翻译、TTS、跟读评测开关。
2. 管理员可为不同学科配置资源中心和 Office 预览开关。
3. 管理员可配置评分维度和权重。
4. 管理员可配置语音和资源相关限制参数。
5. 管理员可查看语音与语言类基础指标。
6. 所有配置变更均可查询审计记录。

## 11. UI 交付说明

1. 对于有定制风格、特殊布局或关键交互要求的页面，需提供对应的 UI 线稿、原型或页面示意作为实现依据。
2. 当前未提供完整 UI 线稿或示意的页面，默认按行业通用规范、常规交互方式和项目既有风格进行设计与实现。
3. 颜色、字号、字重、间距等简单样式调整可在开发过程中配合修改。
4. 涉及页面结构、布局、信息层级或交互逻辑的调整，视为需求变更，需重新评估范围、排期与成本。

## 12. 依赖与前置条件

1. `里程碑一` 管理中台已上线。
2. 后端已提供配置读写、指标查询和审计接口。
3. 语音与语言服务供应商已完成后端适配。

## 13. 风险提示

1. 配置不当会直接影响课堂语音能力可用性。
2. 权重配置错误会造成评分结果不符合预期。
3. 需结合指标变化持续关注服务波动。
