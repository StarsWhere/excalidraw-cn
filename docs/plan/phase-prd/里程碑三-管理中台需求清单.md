# 里程碑三 管理中台 需求清单

## 1. 文档目的

本文档定义智能教学协同系统 `里程碑三` 阶段管理中台新增治理能力的正式范围、页面功能、查询口径与验收标准。

运行环境：新版 Chrome 浏览器中的 Web 管理中台。

## 2. 本阶段交付目标

`里程碑三` 管理中台需交付以下新增治理能力：

1. 完整配置中心。
2. 审计日志查询页。
3. 监控与告警页。
4. 导出任务查询页。
5. 高风险操作追踪能力。

## 3. 本阶段交付范围

1. 配置中心完整页。
2. 审计日志查询页。
3. 监控仪表页。
4. 告警记录页。
5. 导出任务查询页。
6. 高风险操作追踪页。

## 4. 用户角色与使用边界

| 角色   | 使用入口             | 新增可用能力                             |
| ------ | -------------------- | ---------------------------------------- |
| 管理员 | 管理中台 Web         | 完整配置、审计、监控、告警、导出任务追踪 |
| 教师   | 不在中台使用治理页面 | 无                                       |

## 5. 业务流程

### 5.1 配置中心操作流程

1. 管理员进入配置中心。
2. 选择配置分类。
3. 修改参数并提交。
4. 系统校验参数合法性。
5. 写入配置并记录审计日志。

### 5.2 审计追踪流程

1. 管理员进入审计页。
2. 按时间、操作人、对象类型、结果筛选。
3. 查看单条日志详情与 trace 标识。

### 5.3 导出任务追踪流程

1. 管理员进入导出任务页。
2. 按任务类型、发起人、状态筛选。
3. 查看失败原因或下载文件。

## 6. 模块功能需求

### 6.1 配置中心完整页

配置中心必须包含以下分类：

1. 系统参数。
2. 学科能力。
3. 评分规则。
4. AI 参数。
5. 导出规则。
6. 告警阈值。
7. 课堂业务权限。

系统参数固定支持：

1. 设备离线超时时间。
2. 课次恢复策略。
3. 导出命名规则。

AI 参数固定支持：

1. AI 问答开关。
2. 模型选择。
3. 问题最大长度。
4. 回答最大长度。
5. 超时时间。

课堂业务权限固定支持：

1. 试卷导入权限。
2. 测验发起权限。
3. AI 问答可用开关。
4. 课堂总结查看权限。
5. 测验报告导出权限。

### 6.2 审计日志查询页

审计日志查询必须支持以下查询条件：

1. 时间范围。
2. 操作人。
3. 角色。
4. 对象类型。
5. 操作行为。
6. 结果。

审计日志详情必须展示：

1. 日志 ID。
2. 操作人。
3. 角色。
4. 对象类型。
5. 对象 ID。
6. 操作内容。
7. 结果。
8. 错误信息。
9. 时间。
10. 链路标识（如 `trace_id`）。

高风险操作固定包括：

1. 权限变更。
2. 关键配置变更。
3. 批量删除。
4. 批量导出。
5. 评分复算。

### 6.3 监控仪表页

监控仪表页必须展示以下实时或准实时指标：

1. API 失败率。
2. 实时通道连接健康度。
3. 实时通道稳定性。
4. ASR 成功率。
5. TTS 成功率。
6. 评分成功率。
7. AI 回答成功率。
8. 导出任务失败率。
9. 数据库状态。
10. 关键依赖服务状态。

### 6.4 告警记录页

告警记录字段固定为：

1. 告警 ID。
2. 告警类型。
3. 告警对象。
4. 阈值。
5. 实际值。
6. 级别。
7. 触发时间。
8. 恢复时间。
9. 当前状态：未恢复、已恢复、已忽略。

### 6.5 导出任务查询页

导出任务页必须支持：

1. 按任务状态筛选。
2. 按报表类型筛选。
3. 按发起人筛选。
4. 查看失败原因。
5. 下载成功文件。

任务详情必须展示：

1. 任务 ID。
2. 发起人。
3. 发起角色。
4. 报表类型。
5. 状态。
6. 创建时间。
7. 完成时间。
8. 下载地址。
9. 错误信息。

### 6.6 高风险操作追踪页

本页面必须能查看以下内容：

1. 高风险操作列表。
2. 单条操作对应的链路标识（如 `trace_id`）。
3. 相关对象。
4. 相关结果。
5. 是否回滚。

## 7. 数据留存与查询要求

`里程碑三` 管理中台新增留存：

1. 配置中心变更记录。
2. 审计日志查询记录。
3. 监控指标快照。
4. 告警记录。
5. 导出任务查询记录。
6. 高风险操作追踪记录。

## 8. 异常与失败处理

必须显式处理：

1. 配置值不合法。
2. 配置保存失败。
3. 审计查询超时。
4. 监控数据拉取失败。
5. 告警记录加载失败。
6. 导出任务不存在。
7. 下载地址失效。

失败处理规则固定如下：

1. 配置保存失败时不得产生半成功状态。
2. 审计查询失败时必须返回失败原因。
3. 监控页面局部模块失败不得导致整页白屏。

## 9. 非功能要求

1. 配置中心所有修改必须形成审计日志。
2. 审计日志不可被普通教师查看或修改。
3. 监控仪表页默认刷新周期不超过 `60` 秒。
4. 告警列表查询响应控制在 `3` 秒内。
5. 所有导出内容中的文本字段统一按 UTF-8 编码规范处理。
6. 若设备或操作系统版本过旧，或系统字符集配置异常，不保证所有环境中的展示结果均可完全避免乱码。

## 10. 验收标准

1. 管理员可在配置中心维护系统参数、学科能力、评分规则、AI 参数、导出规则、告警阈值和课堂业务权限。
2. 管理员可按条件查询审计日志并查看链路标识。
3. 管理员可查看监控指标和告警记录。
4. 管理员可查询导出任务并下载成功文件。
5. 管理员可追踪高风险操作。

## 11. UI 交付说明

1. 对于有定制风格、特殊布局或关键交互要求的页面，需提供对应的 UI 线稿、原型或页面示意作为实现依据。
2. 当前未提供完整 UI 线稿或示意的页面，默认按行业通用规范、常规交互方式和项目既有风格进行设计与实现。
3. 颜色、字号、字重、间距等简单样式调整可在开发过程中配合修改。
4. 涉及页面结构、布局、信息层级或交互逻辑的调整，视为需求变更，需重新评估范围、排期与成本。

## 12. 依赖与前置条件

1. `里程碑一` 和 `里程碑二` 管理中台已上线。
2. 后端已提供完整配置、审计、监控、告警、导出任务接口。

## 13. 风险提示

1. 指标采集不完整会直接影响中台监控可信度。
2. 高风险操作定义若维护不严，会影响审计有效性。
3. 导出文件保留周期和访问控制若设置不严，会带来数据安全风险。
